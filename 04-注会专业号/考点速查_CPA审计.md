## 第二章 职业道德与独立性

### 基本原则（5项）

1. **诚信**：正直坦诚，不有意误导
2. **客观**：不受偏见或利益冲突影响
3. **专业胜任能力和应有关注**：维持专业水准
4. **保密**：不使用或披露委托人信息
5. **专业行为**：遵守相关法律法规

### 独立性（审计核心）

**实质独立性**：心理状态（真正不受影响）

**形式独立性**：表面无关联（第三方感知）

**禁止情形（威胁独立性）**
- 持有被审单位股票（任何数量）
- 担任被审单位高管或受托管理人
- 与被审单位存在债权债务关系
- 长期担任同一客户主要审计人员（合伙人轮换：≥7年须轮换）

**合伙人轮换**：签字合伙人同一上市公司≤7年须轮换，轮换后冷却期≥2年

## 第四章 审计目标

### 总体目标

**两个目标**
1. 对财务报表整体是否不存在重大错报获取合理保证
2. 依据调查结果出具审计报告

### 认定（Assertion）体系

**交易和事项的认定**

| 认定 | 含义 |
|------|------|
| 发生 | 已记录的交易确实发生 |
| 完整性 | 应记录的交易均已记录 |
| 准确性 | 金额正确计量和描述 |
| 截止 | 交易记录在恰当期间 |
| 分类 | 交易记录在适当账户 |

**期末账户余额的认定**

| 认定 | 含义 |
|------|------|
| 存在 | 资产/负债真实存在 |
| 权利与义务 | 资产归被审计单位 |
| 完整性 | 所有余额均已记录 |
| 计价与分摊 | 余额正确计量 |

## 第五章 审计证据 ⭐⭐⭐

### 审计证据的特征

**充分性**：数量（审计证据的数量）
- 重大错报风险越高 → 需要更多证据
- 质量越高 → 所需数量越少

**适当性**：质量（相关性 + 可靠性）

### 审计证据可靠性排序（高→低）

1. 注册会计师直接观察/查询（亲自获取）
2. 外部证据（函证、外部文件）
3. 内部证据（被审计单位原始凭证）
4. 口头证据（询问获取）

**函证（重要获取手段）**

- **积极式函证**：要求收函方回复（无论是否同意）→ 可靠性高
- **消极式函证**：仅不同意才回复 → 可靠性低，适用于金额小、内控强
- 应收账款必须发函证（除非金额不重要或函证无效时）

### 审计程序类型

| 程序 | 说明 |
|------|------|
| 风险评估程序 | 识别/评估重大错报风险 |
| 控制测试 | 测试内控运行有效性 |
| 实质性程序 | 直接检测错报（分析程序+细节测试）|

## 第七章 风险评估 ⭐⭐⭐

### 审计风险模型

```
审计风险 = 重大错报风险 × 检查风险

重大错报风险 = 固有风险 × 控制风险
（注册会计师不能降低固有风险，只能评估）

检查风险：注册会计师控制（通过调整实质性程序）
```

### 固有风险因素

- 行业特征（竞争激烈、技术变化快）
- 管理层特征（道德水平、能力）
- 业务特征（复杂性、估计判断多）
- 关联方交易多

### 重大错报风险识别

**了解被审计单位及其环境（5方面）**
1. 行业状况、法规环境及适用的财务报告框架
2. 被审计单位的性质（经营模式、组织结构）
3. 会计政策的选择和运用
4. 目标、战略及相关业务风险
5. 财务业绩的衡量和审核

**分析程序（识别异常）**
- 比较本期与上期（趋势分析）
- 比较实际与预期（预算差异）
- 比较同行业数据

## 第八章 重要性

### 概念

**重要性**：错报金额超过一定水平，将影响使用者决策

**重要性与审计风险**：负相关
- 重要性水平高 → 风险可接受范围大 → 所需审计证据少
- 重要性水平低 → 风险可接受范围小 → 所需审计证据多

### 确定重要性的基准

常用基准：
- 税前利润的5%-10%
- 收入的0.5%-1%
- 总资产的0.5%-1%

**实际执行的重要性**：低于财务报表层次重要性，留出余地

## 第九章 内部控制 ⭐⭐⭐

### 内部控制五要素（COSO框架）

1. **控制环境**：管理层的态度和行动（最核心）
2. **风险评估**：识别和分析相关风险
3. **控制活动**：执行管理层指令的政策和程序
4. **信息与沟通**：收集分发所需信息
5. **监控**：评价控制运行质量

### 控制活动类型

| 类型 | 说明 |
|------|------|
| 职责分离 | 授权/记录/保管/核对分开 |
| 授权 | 一般授权+特殊授权 |
| 凭证记录 | 预先编号、及时记录 |
| 实物控制 | 定期盘点 |
| 绩效复核 | 与预算比较 |
| IT控制 | 一般控制+应用控制 |

### 了解内部控制后的决策

```
内控设计合理 → 可以依赖 → 进行控制测试
              → 控制测试有效 → 减少实质性测试
              → 控制测试无效 → 扩大实质性测试

内控设计存在重大缺陷 → 不依赖 → 直接实质性程序
```

**重大缺陷**：最高级别，须向治理层书面沟通

## 第十章 审计抽样

### 两种抽样方法

**统计抽样**：运用概率论和统计学，可量化风险
**非统计抽样**：依赖专业判断

### 抽样风险

**控制测试的抽样风险**
- 过度信赖风险（信赖不足的控制）→ 影响审计效果
- 控制运行有效性过低评估风险 → 影响审计效率

**实质性程序的抽样风险**
- 不正确接受风险（接受含错报的余额）→ 影响审计效果⚠️
- 不正确拒绝风险（拒绝实际正确的余额）→ 影响审计效率

### 样本量的影响因素

控制测试中，样本量与以下因素正相关：
- 可信赖程度（越高 → 越多）
- 可接受偏差率（越低 → 越多）
- 总体规模（总体大时影响小）

## 第十一章 销售与收款循环 ⭐⭐⭐

### 主要认定风险

**收入**：主要关注**发生**认定（虚增收入）和**截止**认定

**应收账款**：主要关注**存在**认定和**计价**认定（坏账）

### 重要实质性程序

**函证应收账款**（最主要）
- 选择函证对象：余额大的、有争议的、余额异常的
- 未收回：执行替代程序

**截止测试**
- 检查报告日前后的销售记录
- 目标：确认收入记录在正确期间

**分析程序**
- 毛利率分析（异常变动→虚增收入）
- 应收账款周转率分析

## 第十六章 完成审计工作 ⭐⭐⭐

### 期后事项

**资产负债表日后至审计报告日**：必须考虑
- 调整事项（说明报表日已存在的情况）→ 调整报表
- 非调整事项（发生在报表日后）→ 披露

**审计报告日后至报告提交日**：无责任主动查询，但知晓须行动

**报告提交日后至财务报告使用期间**：极少情况须处理

### 持续经营评估

**疑虑迹象**
- 财务方面：净负债、到期债务无法偿还、重大营业亏损
- 经营方面：关键管理人员离职、失去主要供应商/客户
- 其他：诉讼、违规等

**注册会计师处理**
- 管理层已采取措施可消除疑虑：标准报告（可能加强调事项段）
- 存在重大不确定性：报告中增加强调事项段
- 有重大怀疑但拒绝披露：保留意见或否定意见

### 书面声明

- 管理层的书面声明≠审计证据的替代品
- 声明内容：承认财务报表责任、证实提供的信息完整
- 声明日期：不早于审计报告日

## 第十七章 审计报告 ⭐⭐⭐

### 审计报告类型

**标准无保留意见报告**：财务报表在所有重大方面公允反映

**非标准报告**

| 报告类型 | 适用情形 | 对报告的影响 |
|---------|---------|------------|
| 带强调事项段的无保留意见 | 重大不确定性但不影响意见 | 加段落 |
| 保留意见 | 存在重大错报/范围限制但非全面影响 | 修改意见 |
| 否定意见 | 错报全面影响财务报表 | 修改意见 |
| 无法表示意见 | 无法获取充分证据且影响全面 | 修改意见 |

**严重程度**：保留意见 < 否定意见；保留意见 < 无法表示意见

### 审计报告要素

1. 标题（"独立审计师报告"）
2. 收件人（董事会或股东）
3. 意见段（核心）
4. 形成意见的基础段
5. 关键审计事项（KAM，适用上市公司）
6. 管理层对财务报表的责任
7. 注册会计师的责任
8. 签名、日期、地址

### 关键审计事项（KAM）

- 仅适用于**上市公司**（强制披露）
- 内容：最重要的风险 + 审计师如何应对
- **不能**对以下事项描述为KAM：导致修改意见的事项、持续经营重大不确定性

## 高频考题易错点

**独立性**
- 审计合伙人轮换：≥7年须轮换，轮换后冷却≥2年
- 持股1股也破坏独立性

**审计证据**
- 函证：积极式可靠性高；消极式可靠性低
- 外部证据比内部证据可靠

**审计风险**
- 审计风险=重大错报风险×检查风险
- 注册会计师只能控制检查风险，不能控制重大错报风险

**审计报告**
- 无法获取充分证据→无法表示意见（不是否定意见）
- 错报全面影响→否定意见（不是保留意见）
- KAM只适用上市公司

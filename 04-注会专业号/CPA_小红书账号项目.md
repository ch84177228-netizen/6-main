每篇小红书文案必须严格按以下格式输出，不得多余内容：

```
标题：（不超过20字）

话题：（10个以内）
时间：（空着）
账号：06红书店铺｜姗姗 店铺大号
```

### 正文写作要求
- 字数：500字以上
- 结构：铺垫 → 展开 → 举例/分析 → 结论
- 分段：短句，一行一句或两三句一段
- 表情符号：每段落搭配相关 emoji
- 随文练习题：每篇考点类文章末尾附1道选择题，答案放评论区
- 诗雨叮嘱：每篇末尾固定模块，做总结提醒

### 配套引流 txt 规范（150字以内）
审核通过后生成，格式同主文案，正文压缩至核心要点+引导语。

### 文案生产 Prompt 模板

```
请根据以下信息写1篇小红书文案：

Day：[X]
日期：[X月X日]
类型：[考点/真题/攻略/种草/冲刺]
科目：[科目名]
对应章节：[第X章 章节名]（审计科目需标注）
选题：[标题参考]

要求：
1. 标题不超过20字
2. 正文500字以上，短句分段，有表情符号，有铺垫/展开/分析/结论
3. 考点类文章末尾附1道随文选择题
4. 末尾有"诗雨叮嘱"模块
5. 话题10个以内
6. 格式：标题/正文/话题/时间（空）/账号

账号：06红书店铺｜姗姗 店铺大号
```

### 文件命名规范
```
Day{N}_{科目}_{主题}_完整版.txt
Day{N}_{科目}_{主题}_引流版.txt
```

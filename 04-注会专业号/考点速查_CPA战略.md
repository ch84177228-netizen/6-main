## 第二章 战略分析 ⭐⭐⭐

### 外部环境分析

**PEST分析**（宏观环境）

| 因素 | 内容 |
|------|------|
| 政治（P）| 政府政策、法律法规、政治稳定性 |
| 经济（E）| GDP、通货膨胀、利率、汇率 |
| 社会（S）| 人口结构、文化、消费习惯 |
| 技术（T）| 技术变革速度、研发投入 |

### 波特五力模型（行业竞争分析）

**五种竞争力量**

1. **现有竞争者的竞争**（核心）：集中度、差异化、退出壁垒
2. **潜在进入者的威胁**：进入壁垒（规模经济、品牌、资本需求、转换成本）
3. **替代品的威胁**：替代品性价比、转换成本
4. **购买者的议价能力**：集中度、标准化程度、信息获取
5. **供应商的议价能力**：集中度、差异化、前向一体化威胁

**高进入壁垒的标志**：规模经济显著、品牌忠诚度高、需大量资本、转换成本高

### 内部环境分析

**价值链分析（波特）**

*基本活动*：进货物流→生产运营→出货物流→市场与销售→售后服务

*支持活动*：企业基础设施/人力资源管理/技术开发/采购

**核心能力分析（VRIO框架）**

| 条件 | 说明 |
|------|------|
| 有价值（V）| 能否利用机会或抵御威胁 |
| 稀缺（R）| 竞争对手是否也拥有 |
| 难以模仿（I）| 是否有历史积累/社会复杂性 |
| 组织支撑（O）| 组织结构能否开发利用 |

### SWOT分析

```
内部：优势（S）、劣势（W）
外部：机会（O）、威胁（T）

四种战略组合：
SO（增长）：用优势抓机会
ST（多元化）：用优势对抗威胁
WO（扭转）：克服弱点抓机会
WT（防御）：减少劣势避开威胁
```

## 第三章 战略选择 ⭐⭐⭐

### 基本竞争战略（波特）

**成本领先战略**
- 以低成本获取竞争优势
- 适合：需求价格弹性大、产品标准化程度高、竞争激烈
- 风险：技术变革使规模经济无效；模仿者出现

**差异化战略**
- 通过产品差异获取溢价
- 适合：客户需求多样、技术壁垒高、品牌价值强
- 风险：差异化被模仿；差异化价值不被客户认可

**集中化战略**（聚焦战略）
- 专注特定细分市场（低成本集中 or 差异化集中）
- 风险：目标市场被大企业侵入

**"卡在中间"**：既不成本领先也无差异，竞争力最弱

### 发展战略

**密集型战略**（现有业务范围内发展）
- 市场渗透：现有产品→现有市场（提升占有率）
- 市场开发：现有产品→新市场
- 产品开发：新产品→现有市场

**一体化战略**
- 纵向一体化：前向（控制分销）/ 后向（控制供应）
- 横向一体化：收购竞争者

**多元化战略**
- 相关多元化：与现有业务有协同效应（更安全）
- 非相关多元化：进入全新领域（风险大，但可分散风险）

### 波士顿矩阵（BCG矩阵）

| 象限 | 市场份额 | 市场增长率 | 策略 |
|------|---------|---------|------|
| 明星（Stars）| 高 | 高 | 投资维持 |
| 现金牛（Cash Cows）| 高 | 低 | 收获现金 |
| 问题（Question Marks）| 低 | 高 | 选择性投资 |
| 瘦狗（Dogs）| 低 | 低 | 撤退/清算 |

### 麦肯锡矩阵（GE矩阵）

- 纵轴：行业吸引力（低/中/高）
- 横轴：业务强度（弱/中/强）
- 9格：投资/维持/收获

## 第四章 战略实施

### 组织结构类型

| 结构 | 特点 | 适用 |
|------|------|------|
| 直线制 | 简单，权力集中 | 小企业 |
| 职能制 | 专业化，协调难 | 单一产品 |
| 事业部制 | 分权，利润中心 | 多元化大企业 |
| 矩阵制 | 双重指挥，灵活 | 项目型企业 |

### 平衡计分卡（BSC）

**四个维度**（相互因果关系）

1. **财务维度**：股东价值（最终目标）
2. **客户维度**：客户满意度→财务
3. **内部流程维度**：核心流程→客户
4. **学习与成长维度**：人员能力→流程

```
学习与成长 → 内部流程 → 客户 → 财务
（因果链）
```

## 第七章 风险评估 ⭐⭐⭐

### 风险识别方法

- **头脑风暴法**：集思广益，适合识别阶段
- **德尔菲法**：专家匿名多轮判断，消除从众效应
- **情景分析法**：构建多种情景评估影响
- **故障树分析（FTA）**：从结果溯源，找根本原因

### 风险评估

**风险矩阵**（二维）

| 维度 | 说明 |
|------|------|
| 可能性 | 风险发生的概率 |
| 影响度 | 风险发生后的损失程度 |

```
风险值 = 可能性 × 影响度
高可能性+高影响度 → 重点关注
```

### 风险度量方法

**定性方法**：描述性评估（高/中/低）

**定量方法**
- 期望值法：∑概率×损失
- 敏感性分析：单因素变动对结果的影响
- **VaR（风险价值）**：在给定置信水平下，持有特定资产在一定期间内的最大潜在损失

## 第八章 风险应对 ⭐⭐⭐

### 四种风险应对策略

| 策略 | 说明 | 适用情形 |
|------|------|---------|
| 风险规避 | 放弃可能引发风险的活动 | 风险极高、代价大 |
| 风险降低 | 采取措施降低概率或影响 | 可控风险 |
| 风险转移 | 通过保险/合同转移给他方 | 财务风险、纯粹风险 |
| 风险承担 | 接受风险，不采取额外措施 | 小风险/收益覆盖风险 |

**风险对冲**（特殊转移方式）：用衍生工具对冲市场风险

### 剩余风险与可接受风险

```
固有风险 - 风险应对效果 = 剩余风险
若剩余风险 ≤ 风险承受度 → 可接受
若剩余风险 > 风险承受度 → 需进一步应对
```

## 第九章 内部控制 ⭐⭐⭐

### 内部控制目标（五项）

1. 经营的合规性和效率
2. 财务报告的可靠性
3. 相关法律法规的遵从
4. 资产安全
5. 战略目标的实现

### 内部控制要素（COSO框架五要素）

1. **控制环境**：诚信价值观、治理结构、权责分配（最重要的基础）
2. **风险评估**：识别/分析影响目标实现的风险
3. **控制活动**：执行管理指令的政策程序（包括IT控制）
4. **信息与沟通**：内外部信息传递
5. **监控活动**：对内控有效性的持续评估

### 控制活动类型

| 类型 | 示例 |
|------|------|
| 职责分离 | 授权/执行/记录/保管分开 |
| 授权控制 | 明确审批权限 |
| 凭证记录 | 预编号、及时记录 |
| 实物控制 | 定期盘点 |
| 信息系统控制 | IT一般控制+应用控制 |

### 内部控制缺陷分类

| 级别 | 说明 |
|------|------|
| 控制缺陷 | 一般性不足 |
| 重要缺陷 | 值得关注，但未达重大 |
| 重大缺陷 | 最严重，须向审计委员会书面报告 |

## 第十章 内部控制评价与审计

### 内部控制评价

**评价主体**：企业管理层（自我评价）

**评价内容**
- 设计有效性：控制设计是否能有效防范风险
- 运行有效性：控制是否被实际执行

**评价报告**：上市公司须披露内部控制评价报告（年报同时披露）

### 内部控制审计

**审计主体**：会计师事务所（独立第三方）

**审计意见类型**
- 无保留意见：内控有效
- 否定意见：存在重大缺陷
- 无法表示意见：受限制，无法判断

## 高频考题易错点

**战略分析**
- 五力模型：供应商/购买者议价能力不是"竞争者"，是影响盈利的力量
- 核心能力：必须同时满足VRIO四条件才能形成持续竞争优势
- BCG：明星业务≠赚钱（需要大量现金投入维持）；现金牛才是现金来源

**战略选择**
- 成本领先≠低价策略（是内部成本控制，定价可以高于竞争对手但仍盈利）
- 差异化战略的前提：客户愿意为差异化支付溢价
- 多元化风险：非相关>相关（协同效应缺失）

**风险应对**
- 风险转移≠消除风险（转移给他方，风险仍然存在）
- 纯粹风险（只有损失）适合保险转移；投机风险不适合
- 风险规避是最彻底但代价最大的策略

**内部控制**
- 内控评价≠内控审计（评价是管理层；审计是会计师事务所）
- 重大缺陷必须书面报告审计委员会（不只是口头）
- 控制活动中：职责分离是最基本的控制活动

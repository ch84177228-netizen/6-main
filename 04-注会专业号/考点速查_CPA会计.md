## 第六章 长期股权投资 ⭐⭐⭐

### 核算方法选择

| 持股比例 | 影响程度 | 方法 |
|---------|---------|------|
| <20% | 无重大影响 | 金融资产（FVOCI或FVTPL）|
| 20%-50% | 有重大影响 | 权益法 |
| >50% | 控制 | 成本法（合并报表用权益法）|
| 特殊情况 | 参与决策 | 也可能用权益法 |

### 初始计量

**企业合并（同一控制）**：以账面价值入账
```
借：长期股权投资（按被投资方账面净资产×持股比例）
    贷：银行存款（支付对价）
    差额调整：资本公积，不足则调盈余公积和未分配利润
```

**企业合并（非同一控制）**：以公允价值入账
```
借：长期股权投资（合并成本=公允价值+相关费用）
    贷：银行存款等
```

**非企业合并取得**：以公允价值+交易费用入账

### 成本法核算

**适用**：控制（个别报表）

**分红处理**
```
宣告分红（购买日后盈利分配）：
借：应收股利
    贷：投资收益

宣告分红（购买日前盈利分配，属于返还投资）：
借：应收股利
    贷：长期股权投资
```

### 权益法核算 ⭐⭐⭐

**被投资方盈利**：
```
借：长期股权投资——损益调整
    贷：投资收益（按持股比例）
```

**被投资方亏损**：
```
借：投资收益
    贷：长期股权投资——损益调整
```
**注意**：亏损以账面价值降至零为限（有长期权益等的要继续亏损直到承担净损失等于长期权益）

**被投资方宣告分红**：
```
借：应收股利
    贷：长期股权投资——损益调整
```

**被投资方其他综合收益变动**：
```
借/贷：长期股权投资——其他综合收益
    贷/借：其他综合收益
```

**内部交易消除（顺流/逆流）**：按持股比例消除未实现内部利润

### 高频经典考题类型

**类型1：顺流交易（母卖子）**
```
母公司向子公司出售存货，存货未对外销售
→ 应消除：未实现内部利润 × 持股比例
借：投资收益
    贷：长期股权投资——损益调整
```

**类型2：逆流交易（子卖母）**
```
子公司向母公司出售存货，存货未对外销售
→ 应消除全部未实现内部利润
借：投资收益
    贷：长期股权投资——损益调整
```

**高频错误**
- 顺流交易：按持股比例消除，不是全额
- 亏损超过账面价值：停止确认，但应披露潜在义务
- 购入时被投资方有超额公允价值：需进行调整（折旧摊销等）

### 长期股权投资减值

- 减值测试：与资产减值损失章节联动
- 一旦计提不可转回

## 第七章 金融工具 ⭐⭐⭐

### 金融资产分类（3类）

**以摊余成本计量的金融资产（AC）**
- 条件：业务模式为持有以收取合同现金流量 + 合同现金流量特征测试（SPPI）
- 典型：持有至到期债券、贷款和应收款项
- 后续：实际利率法计算利息，计提信用减值损失

**以公允价值计量且变动计入其他综合收益（FVOCI）**
- 条件：业务模式为持有以收取合同现金流量及出售 + SPPI测试
- 典型：一般投资者分类为FVOCI的债务工具
- 后续：公允价值变动→OCI；处置时转入损益

**以公允价值计量且变动计入当期损益（FVTPL）**
- 默认：不满足前两类的
- 典型：交易性金融资产、以公允价值计量的权益工具
- 后续：公允价值变动→公允价值变动损益

### 债券投资的摊余成本计算

**实际利率法**
```
每期利息收入 = 期初摊余成本 × 实际利率
溢价购入：
  账面价值 > 面值 → 利息收入 < 票面利息 → 差额冲减摊余成本（溢价摊销）
折价购入：
  账面价值 < 面值 → 利息收入 > 票面利息 → 差额增加摊余成本（折价摊销）
```

**分录（AC类债券）**
```
持有期间：
借：应收利息（票面利率×面值）
    贷：投资收益（实际利率×摊余成本）
    差额：债权投资（折价购入则借记；溢价购入则贷记）

计提信用减值损失：
借：信用减值损失
    贷：债权投资减值准备
```

### 金融负债

**以摊余成本计量**：企业发行的债券等，用实际利率法计算利息费用

**以公允价值计量**：交易性金融负债，变动计入损益

## 第八章 租赁 ⭐⭐⭐

### 承租人（2019年准则改革要点）

**"使用权资产 + 租赁负债"模式**（所有租赁，除短期租赁和低价值资产租赁）

**初始确认**
```
确认使用权资产 = 租赁负债（现值）+ 初始直接费用 + 预付款项 + 复原成本现值
确认租赁负债 = 未付款项现值

借：使用权资产
    贷：租赁负债
        银行存款（初始直接费用等）
```

**后续计量**
```
使用权资产：折旧（同固定资产）
租赁负债：利息费用（实际利率法）

每期付款：
借：租赁负债（本金部分）
    财务费用（利息部分）
    贷：银行存款
```

**短期租赁/低价值资产租赁**（豁免）：简单处理，直接计入当期费用

### 出租人（与旧准则类似）

**融资租赁**：确认应收款项（长期应收款）
**经营租赁**：确认租金收入（按直线法）

## 第十四章 收入 ⭐⭐⭐

### 五步法（同初级，但更复杂）

1. **识别合同**：商业实质+收款可能性+可核实的权利义务
2. **识别履约义务**：判断是否可明确区分
3. **确定交易价格**
   - 可变对价（期望值法/最可能金额法）
   - 重大融资成分
   - 非现金对价：按公允价值
   - 应付客户对价：冲减交易价格
4. **分摊交易价格**：按单独售价比例
5. **履约时确认收入**

### 可变对价

**限制（约束）**：只有高度可能不发生重大收入转回，才能包含

**质量保证**
- 保证类（产品符合约定标准）：不单独计收入，计预计负债
- 服务类（额外服务）：单独履约义务，分摊交易价格

### 合同修改

| 情形 | 处理 |
|------|------|
| 增加明确区分的商品且价格为独立售价 | 新合同 |
| 其他情形 | 原合同变更（未履行部分重新分摊）|

## 第十六章 所得税 ⭐⭐⭐

### 资产负债表债务法

**暂时性差异**
```
应纳税暂时性差异：账面 > 计税 → 递延所得税负债
可抵扣暂时性差异：账面 < 计税 → 递延所得税资产
```

**常见差异举例**

| 项目 | 账面价值 | 计税基础 | 差异类型 |
|------|---------|---------|---------|
| 资产减值准备 | 已计提后净值 | 原值 | 可抵扣（税法不认减值）|
| 公允价值增值 | 公允价值 | 历史成本 | 应纳税（增值未税）|
| 预计负债 | 账面余额 | 0 | 可抵扣 |
| 交易性金融资产增值 | 公允价值 | 历史成本 | 应纳税 |
| 内部开发无形资产 | 摊销后 | 摊销后×150% | 可抵扣 |

**当期所得税（应交所得税）**
```
应交所得税 = 应纳税所得额 × 税率
应纳税所得额 = 税前利润 ± 纳税调整
```

**递延所得税**
```
递延所得税费用 = 递延所得税负债增加 - 递延所得税资产增加
                （或：递延所得税负债减少 + 递延所得税资产减少取负）
```

**所得税费用**
```
所得税费用 = 当期所得税 + 递延所得税
```

### 不确认递延所得税的情况

- 初始确认商誉
- 初始确认与合并无关、也不影响损益的资产/负债

## 第十八章 财务报告 ⭐⭐⭐

### 资产负债表

**列报**：流动/非流动分类
- 流动资产：1年内变现/耗用
- 非流动资产：超过1年

### 利润表

**综合收益概念**
```
综合收益 = 净利润 + 其他综合收益（OCI）
```

OCI项目：
- 权益法核算时被投资方OCI变动
- 可供出售金融资产公允价值变动（FVOCI下）
- 外币报表折算差额
- 套期保值工具公允价值变动

### 现金流量表

**间接法（调整净利润）**

调整项目：
- 加：资产减值损失、固定资产折旧、无形资产摊销、财务费用（利息）
- 加：存货减少、应收账款减少（或减：增加）
- 加：应付账款增加（或减：减少）
- 减：投资收益

## 第十九章 合并财务报表 ⭐⭐⭐

### 合并范围

**控制**：有权主导相关活动 + 参与可变回报 + 影响回报的能力

**特殊情况**：半年内取得的子公司不纳入合并范围（拟出售）

### 合并抵消分录（重点）

**抵消投资与净资产**
```
借：实收资本（被投资方）
    资本公积（被投资方）
    盈余公积（被投资方）
    未分配利润（被投资方）
    商誉（正商誉）
    贷：长期股权投资（母公司账面价值）
        少数股东权益（按净资产×少数股东比例）
```

**抵消内部债权债务**
```
借：应付账款
    贷：应收账款
（同时抵消坏账准备）
```

**抵消内部商品交易未实现损益**
```
借：营业收入（内部销售价格）
    贷：营业成本（内部购入成本）
        存货（期末未售出的未实现利润）
```

**抵消内部股利**
```
借：投资收益
    贷：对子公司的应收股利
```

### 商誉

**正商誉**：合并成本 > 可辨认净资产公允价值×持股比例
- 列在合并资产负债表，不摊销，每年做减值测试

**负商誉**：合并成本 < 可辨认净资产公允价值×持股比例
- 计入当期损益（营业外收入）

## 高频考题易错点

1. **长投权益法**：内部顺流交易按持股比例消除，逆流全额消除（投资者角度）
2. **债券溢折价**：溢价购入账面价值>面值，但实际收益<票面利率
3. **租赁**：2019年后承租人均需确认使用权资产，短期和低价值豁免
4. **所得税**：资产减值损失税法不认，形成可抵扣暂时性差异→递延所得税资产
5. **合并报表**：少数股东损益≠少数股东收益（要确认少数股东承担亏损）
6. **商誉**：不摊销但每年减值测试，减值后不可转回
7. **公允价值变动损益 vs OCI**：FVTPL→损益；FVOCI→其他综合收益

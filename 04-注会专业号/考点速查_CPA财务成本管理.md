## 第六章 资本成本 ⭐⭐⭐

### 个别资本成本

**债务资本成本（税后）**
```
Kd = 税前债务成本 × (1 - 所得税率)
```

**优先股成本**
```
Kp = 优先股股利 ÷ [发行价 × (1 - 筹资费率)]
```

**普通股成本**

*股利增长模型：*
```
Ks = D1 ÷ [P0 × (1-f)] + g
（D1=下期股利，P0=当前股价，f=筹资费率，g=股利增长率）
```

*资本资产定价模型（CAPM）：*
```
Ks = Rf + β × (Rm - Rf)
（Rf=无风险利率，β=系统风险系数，Rm=市场收益率）
```

### 加权平均资本成本（WACC）

```
WACC = Wd×Kd×(1-T) + Wp×Kp + Ws×Ks
```

**权重选择**
- 账面价值权重：稳定，但不能反映资本市场现状
- 市场价值权重：反映现实，但波动大
- 目标资本结构权重：**最合理**（反映未来方向）

## 第三章 资本结构 ⭐⭐⭐

### MM理论

**无税MM理论**（完美市场）
- 资本结构与企业价值无关
- VL = VU（有负债企业价值 = 无负债企业价值）

**有税MM理论**（引入所得税）
- 债务利息可税前扣除（利息税盾）
- VL = VU + T×D（税盾价值 = 税率×债务额）
- 结论：负债越多，企业价值越大（趋向100%负债）

**权衡理论**
- 税盾利益 vs 财务困境成本（破产成本+代理成本）
- 存在最优资本结构（WACC最低点）

**优序融资理论**
- 内部融资（留存收益）> 债务融资 > 权益融资
- 原因：信息不对称（股票发行信号效应）

### 杠杆效应

**经营杠杆（DOL）**
```
DOL = 边际贡献 ÷ 息税前利润（EBIT）
    = (S - VC) ÷ (S - VC - FC)
```

**财务杠杆（DFL）**
```
DFL = EBIT ÷ (EBIT - I - PD÷(1-T))
```

**总杠杆（DTL）**
```
DTL = DOL × DFL = 边际贡献 ÷ (EBIT - I - PD÷(1-T))
```

## 第八章 投资决策 ⭐⭐⭐

### 货币时间价值

**现值与终值**
```
复利终值：FV = PV × (1+i)^n
复利现值：PV = FV ÷ (1+i)^n = FV × (P/F,i,n)
普通年金现值：PVA = A × (P/A,i,n)
永续年金：PV = A ÷ i
```

### 投资决策方法

**净现值法（NPV）** ⭐⭐⭐
```
NPV = Σ[CF_t ÷ (1+k)^t] - C0
NPV > 0：接受（创造价值）
```

**内部收益率（IRR）**
```
使NPV = 0时的折现率
IRR > 资本成本：接受
```
⚠️ NPV与IRR冲突时，以NPV为准

**回收期法**
- 静态：未考虑时间价值，忽略回收期后现金流
- 动态：折现后计算

**获利指数（PI）**
```
PI = 未来现金流量现值 ÷ 初始投资
PI > 1：接受
```

### 投资决策现金流量

**初始现金流量**
```
= 购置成本 + 安装调试费 + 营运资本垫付
  - 旧设备税后残值（出售收入 - 税款）
```

**营业期年净现金流（NCF）**
```
NCF = 净利润 + 折旧
    = （收入 - 付现成本）× (1-T) + 折旧×T
```

**终结期现金流**
```
= 设备税后残值 + 回收营运资本
税后残值 = 残值 - (残值 - 账面价值) × T
```

## 第十章 价值评估基础 ⭐⭐⭐

### 风险与收益

**期望收益率**
```
E(R) = Σ[概率i × 收益率i]
```

**方差与标准差**
```
方差 σ² = Σ[Pi × (Ri - E(R))²]
标准差 σ = √(方差)
```

**变异系数**（相对风险度量）
```
CV = σ ÷ E(R)
（越小越好：单位期望收益对应的风险越低）
```

### 投资组合理论

**组合期望收益**
```
E(Rp) = w1×E(R1) + w2×E(R2)
```

**组合方差**（两资产）
```
σp² = w1²σ1² + w2²σ2² + 2w1w2σ1σ2ρ12
（ρ12 = 相关系数，-1≤ρ≤1）
```

**分散化效果**：相关系数越低，分散化效果越好
- ρ = -1：完全负相关，可完全消除非系统风险
- ρ = +1：完全正相关，无分散化效果

### CAPM模型

```
E(Ri) = Rf + βi × [E(Rm) - Rf]
βi = 系统风险系数（市场风险不可分散）
```

**β系数**
- β = 1：与市场同步
- β > 1：比市场波动大（进攻型）
- β < 1：比市场波动小（防御型）

## 第十一章 企业价值评估 ⭐⭐⭐

### 收益法（现金流折现）

**股权自由现金流（FCFE）**
```
FCFE = 净利润 + 折旧摊销 - 资本支出 - 营运资本增加 + 净债务增加

稳定增长模型：P0 = FCFE1 ÷ (Ks - g)
两阶段模型：= 高速增长阶段PV + 稳定阶段终值PV
```

**企业自由现金流（FCFF）**
```
FCFF = EBIT×(1-T) + 折旧 - 资本支出 - 营运资本增加

企业价值 = FCFF1 ÷ (WACC - g)
股权价值 = 企业价值 - 净债务
```

### 相对价值法（市场法）

| 方法 | 倍数 | 适用场景 |
|------|------|---------|
| 市盈率（P/E）| 股价÷每股收益 | 盈利稳定企业 |
| 市净率（P/B）| 股价÷每股净资产 | 资产密集型 |
| 市销率（P/S）| 股价÷每股销售收入 | 亏损或新创企业 |
| EV/EBITDA | 企业价值÷EBITDA | 跨国/不同杠杆比较 |

## 第十二章 成本核算 ⭐⭐⭐

### 成本计算方法

**品种法**：大批量单一产品（钢铁、水泥等）

**分批法**：小批量、单件产品（飞机、船只、专门订货）

**分步法**：连续大量生产多步骤产品
- 逐步结转（综合结转/分项结转）
- 平行结转

### 成本归集与分配

**直接成本**：直接计入产品

**间接成本（制造费用）**：按分配率分配
```
分配率 = 待分配费用总额 ÷ 分配基础总量
某产品分配额 = 该产品分配基础 × 分配率
```

**完工产品与期末在产品的分配**

*约当产量法：*
```
约当产量 = 实物数量 × 完工程度
单位成本 = 总成本 ÷ （完工产量 + 在产品约当产量）
```

### 作业成本法（ABC）

**核心思想**：成本由作业引起，产品消耗作业

**步骤**：确认作业→归集成本→确定成本动因→计算作业成本率→分配给产品

**优势**：更准确的间接成本分配（适合多品种、间接成本比重大的企业）

## 第十三章 标准成本与变动成本 ⭐⭐⭐

### 标准成本差异分析

**直接材料差异**
```
价格差异 = (实际价格 - 标准价格) × 实际用量
数量差异 = (实际用量 - 标准用量) × 标准价格
```

**直接人工差异**
```
工资率差异 = (实际工资率 - 标准工资率) × 实际工时
效率差异 = (实际工时 - 标准工时) × 标准工资率
```

**变动制造费用差异**
```
耗费差异 = 实际费用 - 实际工时×标准分配率
效率差异 = (实际工时 - 标准工时) × 标准分配率
```

**固定制造费用差异（三差异法）**
```
耗费差异 = 实际费用 - 预算费用
能量差异（产量差异+闲置差异）：
产量差异 = （实际产量-计划产量）× 固定费用标准分配率
闲置差异 = （计划工时 - 实际工时）× 标准分配率
```

### 变动成本法 vs 完全成本法

| 对比项 | 变动成本法 | 完全成本法 |
|-------|----------|----------|
| 固定制造费用 | 期间成本（计入当期损益）| 产品成本（随销售转出）|
| 存货价值 | 较低 | 较高 |
| 利润高低 | 销量多→利润高 | 产量多→利润高 |
| 主要用途 | 内部管理决策 | 外部财务报告 |

## 第十四章 短期经营决策 ⭐⭐⭐

### 相关成本分析

**相关成本**：与决策相关的未来成本（差异成本）

**无关成本**：沉没成本（历史成本）、不变的固定成本

**机会成本**：放弃的最优方案收益，是相关成本

### 常见决策类型

**自制还是外购**
```
若外购单价 < 自制变动成本 + 自制固定成本（可节约）→ 外购
注意：固定成本若不随决策变化，则为无关成本
```

**是否接受特殊订单**
```
接受条件：特殊订单价格 > 变动成本（有剩余产能时）
          OR 特殊订单贡献边际 > 放弃正常订单的损失（无剩余产能时）
```

**亏损产品是否停产**
```
停产条件：该产品贡献边际 < 0（变动成本 > 收入）
若贡献边际 > 0 但利润为负：不应停产（仍能补偿固定成本）
```

**产品组合决策（资源约束）**
```
按单位稀缺资源的边际贡献排序
= 单位产品边际贡献 ÷ 单位产品消耗稀缺资源量
```

## 高频考题易错点

**资本成本**
- 保留盈余（留存收益）有资本成本，是机会成本（无筹资费用）
- 债务成本须乘以(1-T)，因利息税前扣除

**投资决策**
- 折旧本身不是现金流，折旧税盾（折旧×T）才是
- 沉没成本不相关（已发生的历史成本）
- NPV与IRR冲突：选NPV

**成本差异**
- 价格差异用实际数量，数量差异用标准价格
- 有利差异：实际<标准；不利差异：实际>标准

**变动成本法**
- 固定制造费用全部计入当期费用，不进产品成本
- 产销不一致时，与完全成本法利润不同

**企业估值**
- FCFF折现率用WACC；FCFE折现率用Ks（权益资本成本）
- 永续增长模型：g < WACC（否则分母为负，无意义）

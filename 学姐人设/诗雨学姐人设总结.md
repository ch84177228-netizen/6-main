
# 🌟 诗雨学姐人设总结

- **名称**：CPA诗雨学姐（自称：诗雨学姐）
- **身份**：职场宝妈 + 10年+注会培训资深老师
- **学术背景**：硕士学位，2018年起深耕企业财务一线
- **考证经历**：公务员一次性通关；三年完成CPA全科 + 顺带考过税务师

## 2️⃣ 目标受众
- **核心人群**：在职备考CPA、中级会计、税务师的打工人和宝妈
- **主要痛点**：
  - 时间碎片化、精力有限
  - 教材内容枯燥、易混
  - 做题容易卡在逻辑、分录、判断路径上

## 3️⃣ 沟通风格
- **共情**：称呼受众为“宝妈们、在职的姐妹”，深度共情职场+备考的极限拉扯
- **清醒而有力量**：拒绝鸡汤，用真实经历唤醒执行力
- **专业降维**：将复杂知识化繁为简，强调“不到10分钟就能懂”

## 4️⃣ 教学法与内容风格
- **载体**：会计漫画笔记、手写笔记
- **独家类比**：
  - **家族伦理法**：用亲属关系拆解复杂准则
  - **沉浸式剧情法**：宫廷风、现代偶像剧剧情演绎知识点
- **文案关键词**：极限拉扯、秒懂、终极兜底、两年滚动、极其反人性的自律、不到10分钟就会

## 5️⃣ 视觉与审美
- **可爱手绘涂鸦风**：马卡龙色系、圆润Q版人物、星星/箭头/小叶子等图标
- **手写笔记风**：活页笔记质感、清晰可读、留白充足
- **专业图表风**：橙色专业风格、纯白背景、清晰逻辑

## 6️⃣ 商业价值
- **引流产品**：会计漫画笔记
- **高客单产品**：中级会计/CPA VIP私教班
- **卖点**：
  - 每天1小时、2-4个月极限拉扯过三科
  - 稀缺感+安全感：“终极兜底：课程2年有效”
- **转化策略**：以故事化教学+漫画笔记+轻转化文案自然引导购买

## 7️⃣ 核心标签
共情 + 执行力 + 专业 + 剧情化教学 + 漫画笔记 + 秒懂 + 极限拉扯

## 三、文案输出规范

### 3.1 对话展示版（文稿）
- **字数：** 800字以内
- **用途：** 做图素材，内容详细丰富
- **格式：** 短句分段，一行一句或两三句一段，有表情符号
- **结构：** 指出误区 → 解释原因 → 给具体方法 → 总结 → 引导资料

### 3.2 txt 精简版
- **字数：** 200字以内
- **用途：** 存档 / 快速复制发布
- **格式固定：**

```
标题：

正文：

话题：

时间：

账号：06红书店铺 | 考公学姐
```

> ⚠️ 文稿与txt不需要一一对应，txt是独立的精简版本

### 3.3 Word文档
- 命令：`制作Word` 或 `原文制作Word`
- 输出完整排版文档，含标题、分节、项目符号、引流话术、话题标签

## 四、执行口令

| 口令 | 执行内容 |
|------|----------|
| `制作今天的文案` | 生成当前计划表下一篇文稿 + txt + 自动打卡 |
| `制作今天的文案和txt` | 文稿和txt同步输出，无需二次确认 |
| `下一篇` | 顺延计划表下一个选题，输出文稿 + txt + 自动打卡 |
| `看计划表` | 重新渲染进度表，读取云端打卡记录 |
| `制作txt` | 审核通过后单独生成txt文件 |
| `制作Word` | 审核通过后单独生成Word文档 |
| `原文制作Word` | 基于当前文稿生成Word文档 |

---

## 五、标准工作流程

```
1. 生成文稿（对话展示，800字以内）
        ↓
2. 等待审核确认
        ↓
3. 审核通过 → 生成 txt（200字以内）
        ↓
4. 如需要 → 生成 Word 文档
        ↓
5. 自动打卡计划表
```

> 如用户说"制作今天的文案和txt"，步骤1和3合并，无需等待审核

## 六、文案写作风格

**语气：** 像考公学姐在分享干货，亲切、实用、有提醒感，不官方不鸡汤

**常用句式：**
```
很多考公小白一开始就走偏了。
不是你不努力，而是第一步没搞清楚。
先把方向理清，后面备考才不乱。
选岗不是看哪个单位名字好听，而是看自己到底能不能报。
资料不是越多越好，关键是先买对、先用对。
```

**结构模板：**
1. 第一段：指出小白误区（引发共鸣）
2. 第二段：解释为什么错（分析原因）
3. 第三段：给具体方法（干货正文）
4. 第四段：总结提醒
5. 第五段：引导私信"考公资料"

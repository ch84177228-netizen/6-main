# 使用说明｜Codex 中如何使用

## 推荐方式：放 AGENTS.md

把本压缩包里的 `AGENTS.md` 放到你的 Codex 项目根目录。

OpenAI Codex 会读取项目里的 `AGENTS.md` 作为项目指导文件；官方文档说明 Codex 会在开始工作前读取 AGENTS.md，用于提供项目级规则和上下文。

## 建议目录结构

```text
content-factory/
  AGENTS.md
  01-6个主号/
  02-朋友圈/
  03-小红书文案/
  04-做图提示词/
```

## 在 Codex 里怎么提问

示例：

```text
请阅读 AGENTS.md，按照6账号图文风格，把这篇“出租人会计处理”脚本拆成6套出图提示词。
```

```text
请按照 AGENTS.md 中的账号3真人学姐速记版，重写这篇图文做图提示词。
```

```text
请按照 AGENTS.md 中账号6手账冲刺版，把这篇内容做成7页系列图提示词。
```

## 使用重点

- 账号3已经固定为真人学姐速记版，不再用甄嬛故事风。
- 账号5尽量不要卡通插图，主做考点整理。
- 账号6已经改为手账冲刺风，不再用民国风。
- 蜡笔小新账号不要出现“蜡笔小新形象合集、可爱、搞怪、治愈、元气满满”等模板废字，图中文字必须围绕当前考点。

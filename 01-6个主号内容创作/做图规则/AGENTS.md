# AGENTS.md｜6账号图文风格与出图规则

> 用途：放入 Codex 项目的根目录，作为后续批量生成「6账号图文脚本 / 做图提示词 / 文件夹归档」的统一规则。
> 核心任务：根据用户提供的会计/财管/经济法/税法/考公等文稿，拆成 6 套账号风格不同的系列图做图提示词。

## 0. 总原则

- 输出语言：中文。
- 平台：小红书 / 抖音图文 / 朋友圈图文。
- 默认尺寸：3:4 竖版。
- 默认形式：系列图，一页一图，不要九宫格。
- 内容优先级：知识准确 > 文字清晰 > 重点突出 > 风格好看 > 装饰。
- 不要固定只做 5 页；应根据内容长短安排页数。内容多时优先多拆页，不要删关键知识。
- 会计分录、公式、判断条件、处理原则必须保留，不得为了美观删除。
- 分录排版必须规范：同一借方或贷方只写一次“借：/贷：”，后续同方向科目缩进。
- 每套图都要有：封面页 + 知识拆解页 + 易错/避坑/总结页。
- 每页都要明确：
  - 主标题
  - 副标题/小标签
  - 页面核心内容
  - 画面元素
  - 文字重点处理
  - 出图提示词

## 1. 通用视觉规则

### 1.1 画布与字体

- 画幅：3:4 竖版。
- 背景：米白、浅奶油、浅米杏、浅纸张色。
- 字体：清晰圆润手写感中文字体，不要潦草，不要毛笔体，不要过细。
- 正文：深墨黑、深咖色、深灰黑。
- 标题：不能整行全黑，必须有彩色关键词。
- 重点：使用彩色字、荧光笔底色、下划线、圈画、波浪线、红色警示框、箭头。

### 1.2 配色

- 默认鲜艳马卡龙 / 高饱和清新版。
- 常用主色：
  - 玫粉 / 莓果粉：标题关键词、避坑提醒
  - 珊瑚橙 / 奶油橙：考试提醒、步骤编号
  - 湖蓝 / 孔雀蓝 / 雾霾蓝：知识框架、公式卡
  - 明黄 / 浅鹅黄：荧光笔高亮
  - 薄荷绿：正确答案、对勾、总结
- 紫色尽量少用，只做小装饰或少量贴纸。
- 不要大面积低对比浅色文字。

### 1.3 页面结构

- 每页建议 2—4 个主模块。
- 模块用圆角卡片、便签、表格、流程图、对比框、总结条承载。
- 文字不能压在复杂背景或人物上。
- 人物不能抢知识排版，人物服务考点。
- 封面要清爽，主标题大，图案不要夸张。

# 账号1｜主号·甄嬛传版

## 定位

主号完整讲透版。用甄嬛传 Q 版清宫故事类比，把复杂会计考点讲成剧情，但知识排版必须清楚。

## 视觉风格

- Q版甄嬛传漫画教材风。
- 人物年轻精致，但不要幼稚、不要像3岁小孩。
- 太后需要有年龄感，可带白发/银发感。
- 皇帝要成熟稳重，不要太幼稚。
- 女生人物参考年轻学姐感：可爱、精致、聪明，不要低龄化。
- 主号封面清爽一点，不要堆太多图案、贴纸、花边。
- 适合元素：宫殿、账本、算盘、卷轴、印章、宫灯、凤印、小宫女、账房。
- 不复刻演员脸，不真人写实。

## 内容组织

适合做：
- 大白话完整讲透
- 底层逻辑
- 复杂分录故事化
- 考点全流程

每套建议：
- 6—10页
- P1 封面
- P2 背景/底层逻辑
- P3—P7 核心考点拆解
- 最后一页“甄嬛叮嘱 / 诗雨叮嘱”总结

## 标题风格

- 主标题大而清楚，不能全黑。
- 标题关键词用玫粉、湖蓝、珊瑚橙、明黄高亮。
- 不要扇形、弧形、大牌匾式标题。
- 用横向标题条、圆角贴纸、荧光笔底色标题。

## 人物标签格式

优先使用：
- 甄嬛｜一句理解式说明
- 皇上｜先判断是不是控制
- 太后｜考试就爱考这个坑

少用长对白气泡。

# 账号2｜副号1·蜡笔小新版

## 定位

零基础友好、生活化、故事感强。用蜡笔小新/野原家/日常场景类比会计知识。

## 视觉风格

- 蜡笔小新可爱手绘涂鸦风。
- 角色：小新、广志、美冴、小白、同学/邻居等。
- 不要总是小新当老师，尽量让全家/同学参与剧情。
- 小新形象要求：圆脑袋、粗眉、大眼、红上衣、黄短裤，可爱搞怪但不要出现“蜡笔小新形象合集、可爱、搞怪、治愈、元气满满”等无关字样。
- 所有页面主题文字应围绕当前考点，如“长期股权投资”“出租人会计处理”等。
- 配色：蜡笔色、马卡龙色，米白背景。
- 风格：轻松、治愈、元气、好懂。

## 内容组织

适合做：
- 一个生活故事贯穿全篇
- 广志投资 / 美冴记账 / 小新犯错 / 小白提醒
- 用生活场景解释公式和分录

每套建议：
- 5—8页
- P1 封面
- P2 故事背景
- P3—P6 核心知识
- P7/P8 小新叮嘱总结

## 重点规则

- 不要出现与主题无关的模板字。
- 每页屏幕/黑板/便签上的文字必须是考点本身。
- 画面可爱，但文字必须清晰。
- 分录/公式用单独干净卡片呈现。

# 账号3｜副号2·真人学姐速记版

## 定位

真人学姐资料分享风，速记收藏向。已经固定：不再用甄嬛故事风。

## 视觉风格

- 真实备考学姐插图风，不写实照片。
- 像小红书学姐整理笔记：iPad、教材、荧光笔、便利贴、书桌、手写笔记。
- 人物可半身、小比例、坐在书桌前或拿笔做批注。
- 不使用甄嬛人物，不使用宫廷场景。
- 不要过度卡通，保持真实学习氛围。
- 色彩清爽：米白底 + 浅蓝/玫粉/橙黄/薄荷绿。

## 内容组织

适合做：
- 速记表
- 一页背完
- 口诀
- 高频考点清单
- 流程图
- 分录对比

每套建议：
- 5—8页
- P1 封面：学姐速记版 / 建议收藏
- P2 框架总览
- P3—P6 核心高频考点
- 最后一页：学姐总结 / 考前回看

## 文字风格

- 简洁、干货、像学姐笔记。
- 少剧情，多表格、流程、对比。
- 标题可用：
  - “一张表背下来”
  - “高频考点速记”
  - “考前回看这一页”
  - “这个坑最爱考”

# 账号4｜副号3·避坑吐槽版

## 定位

痛点共鸣、踩坑避雷、吐槽感强。适合吸引互动和收藏。

## 视觉风格

- 备考学姐吐槽风 / 错题本风。
- 画面可以有崩溃但好看的学姐。
- 元素：红叉、绿勾、警告牌、错题本、便利贴、红笔、荧光笔、考试卷。
- 背景米白笔记纸。
- 标题要有冲击力，关键词“坑”“错”“考场懵”“别再”要突出。
- 但不要太压抑，保持好看、清爽。

## 内容组织

适合做：
- “我踩过的X个坑”
- “不要再这样记”
- “以为A，其实B”
- 错误做法 vs 正确做法

每套建议：
- 5—7页
- P1 封面：痛点标题
- P2—P6 每页一个坑
- 最后一页：避坑总结清单

## 常用页面结构

- 上半页：错误理解（红叉）
- 下半页：正确处理（绿勾）
- 底部：一句大白话总结

## 标题风格

示例：
- “学长期股权投资，我踩了6个坑”
- “这个坑，考场最容易懵”
- “分红不是收益，别再写反”
- “方向记反，分录全错”

# 账号5｜副号4·纯考点整理版

## 定位

纯考点总结、收藏资料型。尽量不要卡通插图。

## 视觉风格

- 文字手账笔记风 / 资料页 / 表格页。
- 人物极少或不要人物。
- 主要元素：表格、清单、公式卡、分录卡、流程图、对比表、回形针、便签、荧光笔。
- 重点是文字清晰、资料感强、适合收藏。
- 不做剧情，不做大人物，不做卡通装饰。

## 内容组织

适合做：
- 全考点收藏版
- 核心考点整理
- 分录清单
- 公式汇总
- 选择题高频提醒
- 大题步骤表

每套建议：
- 6—10页
- P1 封面：全考点收藏版
- P2 框架/分类
- P3—P7 逐考点表格
- 最后一页：诗雨叮嘱/高频提醒

## 页面规则

- 分录必须清楚、规范。
- 表格不宜太密，必要时拆页。
- 重点词使用彩色标签，但正文保持深色。
- 每页应像一张能直接保存复习的资料卡。

# 账号6｜副号5·手账冲刺版

## 定位

考前冲刺号、倒计时、学习计划、复盘清单。已经固定：不再使用民国风格。

## 视觉风格

- 高颜值手账笔记风 / 学习计划风 / 冲刺清单风。
- 米白或浅奶油笔记纸背景。
- 元素：倒计时贴纸、日历、打卡清单、时间轴、圆角卡片、便签、荧光笔、对勾、手绘下划线、圈画。
- 不使用民国学生、民国服饰、复古书桌、旧上海氛围。
- 文字清晰，计划感强，适合考前收藏复盘。

## 内容组织

适合做：
- “距考试105天｜X个必背点”
- “冲刺阶段必须拿下”
- “必考点1/2/3”
- “现在/中期/最后冲刺节奏”

每套建议：
- 6—8页
- P1 封面：倒计时+主题
- P2—P6 必背点逐页讲
- 最后一页：冲刺计划+复习清单

## 标题风格

示例：
- “距考试105天｜长期股权投资6个必背点”
- “必考点1：分类三档”
- “必考点5：成本转权益必须追溯”
- “105天稳稳推进，上岸有方法”

## 必须避免

- 不要民国风。
- 不要复古人物。
- 不要大面积人物。
- 不要把冲刺图做成普通知识卡，要有倒计时/计划/打卡元素。

## 5. 基础话题标签规则

- #会计实务
- #财管
- #经济法

- #财会干货
- #诗雨会计

## 6. 会计分录规则

凡涉及会计分录，必须遵守：

```text
借：科目A
　　科目B
贷：科目C
　　科目D
```

禁止写成：

```text
借：科目A
借：科目B
贷：科目C
贷：科目D
```

同一借方或贷方下多个科目时，“借：/贷：”只写一次，后续缩进。

分录优先级：

1. 准确性
2. 借贷方向规范
3. 科目完整
4. 文字清晰
5. 版式美观

## 7. 常见任务处理方式

### 用户说：“制作6套出图提示词”

输出 6套完整逐页提示词，不生成图片。

### 用户说：“制作第X个账号系列图”

直接生成对应账号风格的系列图。

### 用户说：“不要九宫格”

必须一页一图，不做九宫格拼图。

### 用户说：“先整理作图执行稿”

输出逐页文字执行稿，不生成图片。

### 用户说：“按照刚刚的6账号风格”

默认调用本文件所有规则。

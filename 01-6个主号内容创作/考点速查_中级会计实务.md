## 第六章 长期股权投资 ⭐⭐⭐

### 核算方法

| 持股比例 | 影响 | 方法 |
|---------|------|------|
| <20% | 无重大影响 | 金融资产 |
| 20%-50% | 有重大影响 | 权益法 |
| >50% | 控制 | 成本法 |

### 成本法

**取得**：以实际成本入账（企业合并中同一控制用账面价值；非同一控制用公允价值）

**持有期间**：只在宣告股利时确认投资收益

**注意区分**：购买日前的股利属于"返还投资"，冲减长期股权投资；购买日后的才是投资收益

### 权益法 ⭐⭐⭐

**调整原则**：按被投资方净资产变动的持股份额调整

**盈亏确认**
```
盈利：借：长期股权投资——损益调整
          贷：投资收益
亏损（账面价值降至零为限）：
      借：投资收益
          贷：长期股权投资——损益调整
```

**其他综合收益变动**
```
借：长期股权投资——其他综合收益变动
    贷：其他综合收益
```

**内部交易处理（中级重点！）**

顺流（投资方卖给被投资方）：按持股比例消除未实现利润
```
借：投资收益
    贷：长期股权投资——损益调整
```

逆流（被投资方卖给投资方，存货未售出）：按持股比例消除
```
借：投资收益
    贷：长期股权投资——损益调整
```

## 第七章 金融资产 ⭐⭐⭐

### 三类分类

1. **以摊余成本计量（AC）**：持有至到期债券
   - 后续：实际利率法计息；计提信用减值损失
   
2. **以公允价值计量且变动计入OCI（FVOCI）**
   - 债务工具：信用减值损失影响损益
   - 权益工具（指定）：变动只进OCI，不得转入损益
   
3. **以公允价值计量且变动计入损益（FVTPL）**
   - 默认兜底类，交易性金融资产

### 摊余成本法（债券）

**溢价购入（账面>面值）**
```
收到利息：借：应收利息（票面利率×面值）
          贷：投资收益（实际利率×摊余成本）
          贷：债权投资（差额=溢价摊销）
```

**折价购入（账面<面值）**
```
收到利息：借：应收利息（票面利率×面值）
          借：债权投资（差额=折价摊销）
          贷：投资收益（实际利率×摊余成本）
```

### 信用减值损失

**三阶段减值模型**

| 阶段 | 信用风险 | 减值计量 |
|------|---------|---------|
| 第一阶段 | 初始确认起未显著增加 | 12个月预期信用损失 |
| 第二阶段 | 显著增加（但未发生减值）| 整个存续期预期信用损失 |
| 第三阶段 | 已发生信用减值 | 整个存续期预期信用损失 |

## 第十四章 收入 ⭐⭐⭐

### 五步法（中级深度）

**第二步：识别履约义务**
- 可明确区分的商品/服务 = 单独履约义务
- 判断标准：客户能从该商品单独或与其他现成资源结合获益 + 与合同中其他承诺可明确区分

**第三步：确定交易价格**

*可变对价*
- 期望值法（多个可能结果时）
- 最可能金额法（只有两个可能结果时）
- 限制：需高度可能不发生重大收入转回

*重大融资成分*
- 合同中隐含融资安排（付款时间与控制权转移差异明显）
- 调整交易价格（折现/加利息）
- 豁免：期限≤1年

**第四步：分摊交易价格**
- 按各履约义务的单独售价比例分摊
- 无单独售价的：采用调整市场评估法/预期成本加成法/余值法

**特殊销售安排**

| 情形 | 处理 |
|------|------|
| 附退回条款 | 确认预期不退回部分的收入；退货负债+资产 |
| 附质量保证（保证型）| 确认预计负债 |
| 附质量保证（服务型）| 单独履约义务分摊价格 |
| 附客户额外购买选择权 | 若有重大权利，单独履约义务 |
| 委托代售（代理人）| 净额确认（手续费）|
| 授权许可（使用权）| 时点确认 |
| 授权许可（访问权）| 时段确认 |

## 第十六章 所得税 ⭐⭐⭐

### 资产负债表债务法

**暂时性差异 → 递延所得税**

**常见可抵扣暂时性差异（形成递延所得税资产）**
- 资产减值损失（税法不认）
- 预计负债（税法不认）
- 研发费用加计扣除
- 交易性金融资产公允价值下降（账面<计税）

**常见应纳税暂时性差异（形成递延所得税负债）**
- 交易性金融资产公允价值上升（账面>计税）
- 加速折旧（税法折旧>会计折旧，账面>计税）
- 分期收款销售（税法已全额确认，账面分期）

**所得税费用计算**
```
当期所得税（应交所得税）= 应纳税所得额 × 税率
递延所得税费用（或收益）= 递延所得税负债增加额 - 递延所得税资产增加额
所得税费用 = 当期所得税 + 递延所得税费用
```

**特别注意**：某些暂时性差异对应的递延所得税直接计入所有者权益（OCI），不经过损益

## 第十八章 财务报告 ⭐⭐⭐

### 资产负债表

**重要勾稽关系**
- 合并资产 = 合并负债 + 合并所有者权益（含少数股东权益）
- 期末未分配利润 = 期初未分配利润 + 本年净利润 - 分配股利

**需要了解的项目列报**
- 交易性金融资产：流动资产
- 长期应收款超1年：非流动资产
- 1年内到期的非流动负债：流动负债

### 利润表

**综合收益**
```
净利润
+其他综合收益（净额）
  不可转入损益：权益法下OCI变动；FVOCI权益工具公允价值变动
  可转入损益：FVOCI债务工具；套期；外币折算
=综合收益
```

### 现金流量表（间接法重点）

**净利润调整为经营活动现金流**

调增项目（加回）：
- 固定资产折旧、无形资产摊销
- 使用权资产折旧（租赁准则）
- 固定资产、无形资产减值损失
- 处置固定资产损失
- 存货增加（取负则调减）

调减项目（扣减）：
- 应收账款增加
- 存货增加

## 借款费用（第十章）

**资本化条件（同时满足）**
1. 资产支出已发生
2. 借款费用已发生
3. 使资产达到预定可使用状态的必要的购建/生产活动已开始

**资本化金额计算**
```
一般借款资本化利息 = 加权平均支出（超出专项借款部分）× 加权平均利率
专项借款资本化利息 = 借款费用 - 闲置借款的投资收益
```

## 非货币性资产交换（第十三章）

### 是否以公允价值计量

**满足以下任一：**
1. 该交换具有商业实质
2. 换入/换出资产的公允价值能够可靠计量

**以公允价值计量**（有商业实质）：
```
换入资产 = 换出资产公允价值 ± 补价 + 相关税费
损益 = 换出资产公允价值 - 换出资产账面价值
```

**不以公允价值计量**（无商业实质）：
```
换入资产 = 换出资产账面价值 ± 补价 + 相关税费
不确认损益
```

## 债务重组（第十二章）

### 方式

1. **以资产清偿债务**：债务人让渡资产（公允价值），差额计入营业外收入/支出
2. **将债务转为权益工具**：按股票公允价值，差额计入营业外收入
3. **修改其他条款**：未来应付金额现值 < 账面价值，差额计入营业外收入

### 债权人

以摊余成本计量的：重组损失 = 账面价值 - 未来现金流量现值
以公允价值计量的：按公允价值确认

## 高频考点与常见错误

**长期股权投资**
- 顺流逆流交易按持股比例消除（不是全部）
- 亏损超账面价值停止确认（保留承担损失的额外义务时继续）

**金融资产**
- 交易费用：FVTPL类直接计损益（买入时）；其他类计入初始成本
- 股息分红：FVTPL类收到后计投资收益；FVOCI权益工具也计投资收益

**收入**
- 合同负债≠预收账款（但可以是同一内容，只是列报科目名称不同）
- 退货负债：收到退货时冲负债，不是确认收入

**所得税**
- 不确认递延所得税的：初始确认商誉；初始确认与合并无关且不影响损益的资产

**借款费用**
- 厂房装修期间不满足资本化条件（非"使其达到预定可使用状态"）
- 已完工部分停止资本化

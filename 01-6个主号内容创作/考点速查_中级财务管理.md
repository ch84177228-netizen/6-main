## 第二章 财务报表分析 ⭐⭐⭐

### 偿债能力分析

**短期偿债能力**

| 指标 | 公式 | 说明 |
|------|------|------|
| 流动比率 | 流动资产÷流动负债 | 一般>2较好 |
| 速动比率 | (流动资产-存货)÷流动负债 | 一般>1较好 |
| 现金比率 | (货币资金+交易性金融资产)÷流动负债 | 最保守 |

**长期偿债能力**

| 指标 | 公式 |
|------|------|
| 资产负债率 | 负债总额÷资产总额×100% |
| 权益乘数 | 资产总额÷股东权益 |
| 产权比率 | 负债总额÷股东权益 |
| 利息保障倍数 | (利润总额+利息费用)÷利息费用 |

### 营运能力分析

| 指标 | 公式 |
|------|------|
| 存货周转率 | 营业成本÷平均存货 |
| 存货周转天数 | 365÷存货周转率 |
| 应收账款周转率 | 营业收入÷平均应收账款 |
| 应收账款周转天数 | 365÷应收账款周转率 |
| 总资产周转率 | 营业收入÷平均总资产 |

### 盈利能力分析

| 指标 | 公式 |
|------|------|
| 营业净利率 | 净利润÷营业收入×100% |
| 总资产净利率（ROA）| 净利润÷平均总资产×100% |
| 净资产收益率（ROE）| 净利润÷平均净资产×100% |

### 杜邦分析体系

```
ROE = 净利润÷净资产
    = (净利润÷营业收入) × (营业收入÷总资产) × (总资产÷净资产)
    = 营业净利率 × 总资产周转率 × 权益乘数
```

**四个关键变量**：盈利能力 × 营运能力 × 财务杠杆 = ROE

## 第五章 资本成本 ⭐⭐⭐

### 个别资本成本

**债务资本成本（税后）**
```
Kd = 利率 × (1 - 所得税率)
```

**优先股资本成本**
```
Kp = 每年股利÷发行价格（净额）
```

**普通股资本成本**

*股利增长模型：*
```
Ks = D1÷P0 + g
（D1=下期股利，P0=当前股价，g=股利增长率）
```

*资本资产定价模型（CAPM）：*
```
Ks = Rf + β × (Rm - Rf)
（Rf=无风险利率，β=系统风险系数，Rm=市场收益率，Rm-Rf=市场风险溢价）
```

### 加权平均资本成本（WACC）

```
WACC = Σ(各资本占比 × 各资本成本)
     = Wd×Kd + Wp×Kp + Ws×Ks
```

**权重的选择**：账面价值权重 / 市场价值权重（更合理）/ 目标价值权重

## 第六章 投资决策 ⭐⭐⭐

### 货币时间价值

**终值（FV）与现值（PV）**
```
单利：FV = PV × (1 + i×n)
复利：FV = PV × (1+i)^n
现值：PV = FV × (1+i)^(-n)
```

**年金**
```
普通年金现值：PVA = A × [(1-(1+i)^(-n))÷i]
              = A × PVIFA(i,n)

普通年金终值：FVA = A × [(1+i)^n - 1)÷i]
              = A × FVIFA(i,n)
```

**永续年金**
```
PV = A÷i
（适用于优先股、永久债券估值）
```

### 投资决策方法

**净现值法（NPV）** ⭐⭐⭐
```
NPV = Σ[各期现金流量 × 折现系数] - 初始投资
NPV > 0：接受项目
NPV < 0：拒绝项目
多个方案：选NPV最大的
```

**内部收益率法（IRR）**
```
使NPV=0时的折现率即为IRR
IRR > 资本成本：接受
IRR < 资本成本：拒绝
```
**注意**：NPV与IRR可能结论不一致（互斥项目时），以NPV为准

**回收期法（PP）**
```
静态：累计现金流量回正的期间
动态：折现后的累计现金流量回正的期间
```
缺点：忽略回收期后的现金流量

**获利指数法（PI）**
```
PI = 未来现金流量现值÷初始投资
PI > 1：接受
```

### 投资决策的现金流量

**初始现金流量**：设备购置+安装+运营资本垫付-旧设备残值（税后）

**营业期现金流量**
```
每年净现金流量 = 营业收入 - 付现成本 - 所得税
             = 净利润 + 折旧（非付现成本）
             = （收入-付现成本）× (1-税率) + 折旧×税率
```

**终结期现金流量**：设备残值（税后）+回收营运资本

## 第七章 流动资产管理

### 现金管理

**最佳现金持有量模型**

*存货模型（鲍莫尔模型）*
```
最佳转换量 C* = √(2TF÷K)
（T=总现金需要量，F=每次转换固定成本，K=持有现金的机会成本率）
最低总成本 = √(2TFK)
```

*随机模型（米勒-奥尔模型）*：适用于现金流量不确定的情况

### 应收账款管理

**信用政策**：信用标准 + 信用条件 + 收账政策

**信用成本收益分析**
```
净收益 = 新方案收益增加 - 机会成本增加 - 坏账损失增加 - 管理费用增加
```

**应收账款平均余额**
```
= 年赊销额÷360 × 平均收账天数
```

### 存货管理

**经济订货量（EOQ）**
```
EOQ = √(2DF÷K)
（D=年需求量，F=每次订货成本，K=单位存货持有成本）
最低存货总成本 = √(2DFK)
年订货次数 = D÷EOQ
```

## 第八章 筹资管理 ⭐⭐⭐

### 筹资方式

**权益筹资**
- 普通股：无固定还款义务，成本高于债务
- 留存收益：无筹资费用，成本最低（机会成本）

**债务筹资**
- 银行借款：灵活，利息税前扣除
- 债券：可公开市场流通
- 融资租赁：实质是借款

### 资本结构理论

**MM理论（有税）**：引入债务可以减税（利息税盾），企业价值随债务增加而增加

**权衡理论**：在税盾利益与财务困境成本之间寻求最优资本结构

**最优资本结构**：WACC最低 / 企业价值最大时的资本结构

### 长期债券的发行

**平价发行**：票面利率 = 市场利率
**溢价发行**：票面利率 > 市场利率（发行价 > 面值）
**折价发行**：票面利率 < 市场利率（发行价 < 面值）

## 第十章 杠杆效应 ⭐⭐⭐

### 三种杠杆

**经营杠杆（DOL）**
```
DOL = 息税前利润变动率÷销售量变动率
    = 边际贡献÷息税前利润（EBIT）
    = (S - VC) ÷ (S - VC - FC)
```
固定成本越高，DOL越大，经营风险越大

**财务杠杆（DFL）**
```
DFL = EBIT变动率÷EPS变动率（倒数关系）
    = EBIT ÷ (EBIT - I - PD÷(1-T))
（I=利息，PD=优先股股利，T=所得税率）
```
债务越多，DFL越大，财务风险越大

**总杠杆（DTL）**
```
DTL = DOL × DFL
    = 边际贡献 ÷ (EBIT - I - PD÷(1-T))
```

### 盈亏平衡分析

```
盈亏平衡点（销售量）= 固定成本 ÷ 单位边际贡献
盈亏平衡点（销售额）= 固定成本 ÷ 边际贡献率
```

## 第十一章 企业价值评估

### 收益法（现金流折现法）

**股权自由现金流（FCFE）**
```
FCFE = 净利润 + 折旧 - 资本支出 - 营运资本增加 + 新借款 - 还款
企业股权价值 = FCFE ÷ (Ks - g)  [稳定增长模型]
```

**企业自由现金流（FCFF）**
```
FCFF = 息税前利润×(1-税率) + 折旧 - 资本支出 - 营运资本增加
企业价值 = FCFF ÷ (WACC - g)
```

### 相对价值法（市场法）

| 方法 | 公式 |
|------|------|
| 市盈率法（P/E）| 股权价值 = 目标EPS × 可比P/E |
| 市净率法（P/B）| 股权价值 = 目标每股净资产 × 可比P/B |
| 市销率法（P/S）| 股权价值 = 目标每股销售收入 × 可比P/S |

## 高频考点与常见错误

**财务分析**
- 速动资产：流动资产 - 存货（有时也减预付款）
- 权益乘数 = 资产÷净资产，不是权益乘财务杠杆

**资本成本**
- 债务成本要乘以（1-税率），因为利息可税前扣除
- CAPM中β系数反映系统风险（不可分散）

**投资决策**
- NPV法和IRR法结论不一致时，以NPV法为准
- 折旧本身不是现金流，但折旧税盾（折旧×税率）是

**杠杆**
- DOL用边际贡献÷EBIT，分子分母都不含利息
- DFL用EBIT÷(EBIT-利息)，分母减去利息
- 记忆：经营杠杆"操"(到)EBIT，财务杠杆从EBIT"操"(到)EPS

**现金管理**
- EOQ公式：√(2DF÷K)，订货成本在分子，持有成本在分母

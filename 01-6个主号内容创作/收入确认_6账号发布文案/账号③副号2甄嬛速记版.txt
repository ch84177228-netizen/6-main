🔑 五步法速记对照表
━━━━━━━━━━━━━━━━━━

第①步 | 皇上颁旨，旨意是否合法有效
→ 识别合同
→ 5个条件：双方认可 + 权利义务可识别 + 有明确对价 + 商业实质 + 收款可能性高
→ 5个全满足才能继续

第②步 | 数清楚旨意里包含几件事
→ 识别履约义务
→ 判断标准（两个同时满足）：客户能单独获益 + 与其他承诺可明确区分
→ 一份合同≠一个义务，要逐项拆开

第③步 | 谈清楚彩礼总额，还要做4项调整
→ 确定交易价格
→ ①可变对价（期望值法/最可能金额法，有限制）
→ ②重大融资成分（付款与交货差异明显→折现，≤1年可豁免）
→ ③非现金对价（按公允价值折算）
→ ④应付客户对价（冲减交易价格，不是费用）

第④步 | 按各自市场价比例拆分彩礼
→ 分摊交易价格
→ 优先用可观察的单独售价
→ 无可观察价格：调整市场评估法 / 预期成本加成法 / 余值法

第⑤步 | 事情做完才能记账，区分时间点和时段
→ 履约时确认收入
→ 时段3条件（满足任一）：同时获得并消耗 / 资产对客户有价值 / 无替代用途+有权收款
→ 不满足时段→时间点（看控制权转移的5个迹象）

━━━━━━━━━━━━━━━━━━
⚠️ 特殊销售安排速记
━━━━━━━━━━━━━━━━━━

附退回条款
→ 预期不退回部分 → 确认收入
→ 预期退回部分 → 确认退货负债（不是收入）
→ 同时确认退货资产（收回商品的账面价值）

质量保证
→ 保证型（产品符合约定标准）→ 预计负债，不单独确认收入
→ 服务型（提供额外检测/维修服务）→ 单独履约义务，分摊交易价格

主要责任人 vs 代理人
→ 主要责任人：全额确认收入（自己承担库存风险 + 可自主定价）
→ 代理人：净额确认（只确认手续费/佣金）

附客户额外购买选择权（重大权利）
→ 有重大权利（显著低于正常售价）→ 单独履约义务
→ 无重大权利（正常促销）→ 不单独处理

授权许可
→ 使用权型（固定时间点的知识产权）→ 时间点确认
→ 访问权型（持续更新/接触知识产权）→ 时段确认

━━━━━━━━━━━━━━━━━━
❌ 高频考试陷阱
━━━━━━━━━━━━━━━━━━

陷阱①：收到预付款 → 合同负债，不是收入
陷阱②：货物发出 ≠ 控制权转移（要看客户何时取得控制权）
陷阱③：一个合同只算一笔收入（错！要识别多个义务）
陷阱④：可变对价全部纳入交易价格（错！有限制条件）
陷阱⑤：融资成分<1年也要调整（错！≤1年可以豁免不调整）
陷阱⑥：退货直接冲收入（错！应设退货负债+退货资产）
陷阱⑦：代理人全额确认（错！代理人净额，即佣金）

━━━━━━━━━━━━━━━━━━
📝 常考场景对应
━━━━━━━━━━━━━━━━━━

卖货 → 时间点（客户取得控制权时）
装修/建造合同 → 时段（满足条件③）
软件订阅/物业费 → 时段（满足条件①）
软件永久授权 → 时间点（使用权型）
在线课程订阅 → 时段（访问权型）
平台抽佣 → 代理人净额确认
商品返利 → 可变对价，估计后冲减

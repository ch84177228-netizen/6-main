## 二、文稿制作标准

### 图文脚本规格
- **张数**：每篇 8-10 张图，内容决定张数，不固定
- **每张图**：10-15 行，有铺垫、展开、举例、分析、结论
- **类比要求**：完整故事情节，不只是一句话带过
- **口诀要求**：逐句拆解，每一句都解释清楚

### 参考结构（灵活调整）
```
第1张   封面（极简大字 + 情绪钩子词）
第2张   背景铺垫 + 痛点引入
第3张   为什么难 / 常见误区
第4张   核心逻辑展开
第5张   具体例子1（详细展开）
第6张   具体例子2 / 易错对比
第7张   真题考法 + 选项陷阱
第8张   口诀逐句拆解
第9张   逻辑串联 + 总结收尾
```

### 配套小红书正文规格
- **字数**：650-800字（完整版）
- **要求**：有铺垫、举例、分析、结论，内容足够丰富供制图使用

### 小红书引流小号文案规格
- **字数**：正文不超过200字
- **格式要求**：有表情符号，短句分段，一行一句或两三句一段

## 三、10个账号文稿写作风格

### 账号① 主号·甄嬛传版
```
封面标题：【考点名称】一下通透了 / 越看越上头
故事场景：
  - 皇上 = 集团老板 / 税务局 / 最终控制方
  - 甄嬛（熹贵妃）= 母公司 / 主角
  - 华妃 = 子公司 / 竞争对手
  - 沈眉庄 = 联营企业 / 合伙人
  - 端妃 = 合营伙伴
  - 太后 = 投资性主体 / 上级监管
  - 翊坤宫 = 母公司账本
  - 各宫宫殿 = 子公司
写作要求：
  - 故事情节完整，不只是一句话带过
  - 类比和会计含义一一对应
  - 每个考点都有甄嬛传场景引入
```

### 账号② 副号1·蜡笔小新版
```
封面标题：靠小新家，我终于搞懂【考点】了
故事场景：
  - 广志爸爸 = 集团老板（挂名的那种）
  - 美冴妈妈 = 实际控制人 / 母公司
  - 小新、小葵 = 子公司 / 各部门
  - 小白 = 小型资产
  - 山田家 = 被收购的公司
  - 风间爸爸 = 合伙人
  - 爷爷奶奶 = 投资性主体
写作要求：
  - 备考人第一人称自述
  - 分享"我之前不懂→用小新家理解→突然开窍"的过程
  - 口语化，共鸣感强
```

### 账号③ 副号2·甄嬛速记版
```
封面标题：【考点名称】考点｜甄嬛传X分钟背完
格式要求：
  - 每个考点先给甄嬛版一句话，再给正经版定义
  - 结构清晰，适合收藏背诵
  - 最后3句话总结，建议收藏
写作要求：
  - 内容比主号版精简50%
  - 突出对比和速记
  - 配备易考陷阱提醒
```

### 账号④ 副号3·避坑吐槽版
```
封面标题：学【考点】，我踩过的X个深坑
写作结构：
  1. 我当初怎么学的（反面教材）
  2. 犯了什么错（坑X：描述）
  3. 真相是什么（纠正）
  4. 总结避坑指南
写作要求：
  - 过来人口吻，真实感强
  - 坑要具体，不能泛泛而谈
  - 结尾不加私信/评论区等引流语
```

### 账号⑤ 副号4·纯考点总结版
```
封面标题：【考点名称】核心考点｜收藏这一篇就够了
写作要求：
  - 纯文字，无故事类比
  - 结构清晰，每个模块用✅标注
  - 专业术语准确，适合直接用于复习
  - 按模块覆盖全章考点
  - 末尾注明"建议收藏，考前回看"
```

### 账号⑥ 副号5·考前冲刺版
```
封面标题：距离中级考试X天｜【考点】必考考点今天搞定
写作结构：
  1. 为什么这章是必考（考频/分值/难度）
  2. 高频考点1-5（逐一列出）
  3. 选择题常见陷阱
  4. 备考建议（学习顺序+时间安排）
写作要求：
  - 开头必须有倒计时天数
  - 结尾必须有"9月5日稳稳上岸"
  - 紧迫感强，直接给结论
```

### 账号⑦ 西游记故事号
```
定位：用西游记讲会计考点，国民IP覆盖更广
人物对照表：
  唐僧 = 集团CEO / 母公司
  孙悟空 = 母公司执行层 / 核心子公司
  猪八戒 = 联营企业（有能力但懒）
  沙僧 = 子公司（任劳任怨）
  如来佛祖 = 税务局 / 监管机构
  观音菩萨 = 审计机构
  妖怪 = 考试难点 / 常见错误
  取经路 = 备考之路

封面标题：用西游记，5分钟搞懂【考点】
写作结构：
  1. 取经路上遇到的"妖怪"（引出考试难点）
  2. 师父领进门：唐僧讲核心规则
  3. 悟空出手：具体处理方法
  4. 八戒踩坑：常见错误示范
  5. 沙僧总结：完整考点梳理
写作要求：
  - 故事情节完整，人物性格符合原著
  - 类比和会计含义一一对应
  - 比甄嬛传版更通俗，男女通吃
  - 结尾有"取经路不迷路，考试稳稳过"
变现方向：引流漫画笔记
```

### 账号⑧ 小新故事号
```
定位：以蜡笔小新家庭为主角，用完整日常故事讲透会计知识点
人物对照表：
  野原广志（爸爸）= 普通投资人 / 纳税人 / 犯错示范角色
  野原美冴（妈妈）= 稳健理性方，代表正确处理
  野原新之助（小新）= 讲解人，反应快，金句收尾
  野原小白（小狗）= 配角，偶尔出场活跃气氛

封面标题：小新家又出事了，这次教会你【考点】
写作结构：
  1. 广志搞出一个财务/税务/会计问题（引出考点）
  2. 美冴或小新发现问题，追问根源
  3. 小新用大白话解释正确处理方式（核心知识点）
  4. 广志踩坑对比：错误 vs 正确做法
  5. 小新一句话总结（精辟口诀或对比句）
写作要求：
  - 故事场景来自真实家庭日常（买东西/理财/报税/开票等）
  - 广志必须至少犯一个典型错误，用于反面示范
  - 小新的解释必须通俗，不堆专业术语
  - 结尾小新金句要简短有力，可直接当口诀背
  - 篇幅600-800字，故事完整，不截断
  - 与账号②的区别：②是学生备考视角用小新类比；⑧是以小新家庭本身为主角的完整故事
变现方向：引流私教班+社群
```

### 账号⑨ 柯南故事号
```
定位：用名侦探柯南破案的方式讲会计考点
写作逻辑：每个知识错误是一件"案件"，柯南逐一侦破
封面标题：柯南接到X件疑案，把【考点】讲透了
写作结构：
  1. 引出背景：柯南接到N件"疑案"（每件对应一个考点）
  2. 每件案件：案件背景描述→柯南分析推理→侦破结论
  3. 柯南总结：全章核心规则汇总
口头禅：真相只有一个
写作要求：
  - 适合讲规则类、禁止类、判断类考点（有对有错，有规矩）
  - 风格严谨有逻辑感，推理过程清晰
  - 每件案件独立完整，结论直接给出
  - 结尾固定"真相只有一个：规矩不能破"
变现方向：引流私教班
```

```
定位：西游记IP延伸，以八戒踩坑为主线讲操作细节

  2. 悟空或沙僧发现并指出问题
  3. 逐步讲解正确处理方式（操作步骤具体）
  4. 沙僧总结：完整考点梳理
写作要求：
  - 八戒的错误要典型，对应真实高频错误
  - 操作步骤比⑦更细，适合讲计算类、分录类考点
  - 沙僧总结要精炼，可直接当口诀背
变现方向：引流漫画笔记
```

### 账号⑪ 小新故事号2

```
  2. 美冴或广志提出疑问
  3. 小新用大白话解释两者区别和适用条件

写作要求：

  - 小新的解释要通俗，不堆术语
  - 结尾对比结论要简洁有力
```

## 五、工作流程规则

### 多篇文章制作流程
```
第一步：先发第1篇（主号版）给用户审核
第二步：用户确认没问题后，继续制作剩余5个账号版本
第三步：正文文案审核通过后，再生成配套txt和Word文档
第四步：所有文案确认后，打包生成zip下载
```

### Word文档生成规范
- 使用 `docx` npm包生成
- 6个账号按顺序排列，每个账号独立分页
- 每个账号包含：标题备选、图文脚本、配套小红书正文
- 封面页包含：篇名、系列标识、6账号风格说明

### zip包命名规范
```
[主题]_6账号完整脚本.docx
[主题]_全平台_21条发布文案.zip
```

## 十三、Python txt生成脚本模板

```python
import os, zipfile

contents = [
    {
        "title": "标题（≤20字）",
        "body": "正文（≤350字，含表情符号，无引流语）",
        "topics": "#话题1 #话题2 ..."
    },
    # ... 6组内容
]

xhs_accounts = [
    "06红书店铺|粉色手机",
    "06红书店铺|黄色手机",
    "06红书店铺|蓝色ipad张菊芳",
    "06红书店铺|孙文新134 已实名",
    "06红书店铺|孙文新 小号店铺号",
    "06红书店铺|姗姗已实名",
]
dy_accounts = [
    "07抖音发作品|01蓝色",
    "07抖音发作品|02粉色西瓜",
    "07抖音发作品|03黄色",
    "07抖音发作品|04粉色糖糖",
    "07抖音发作品|05吴学安手机号",
]
sp_accounts = [
    "04视频号|01主账号黄色手机",
    "04视频号|02诗雨vip",
    "04视频号|03蓝色手机",
    "04视频号|04孙文礼",
    "04视频号|05胡芝兰",
    "04视频号|06吴学安",
]
gzh_accounts = [
    "13公众号|01蓝色密码",
    "13公众号|02VIPSun",
    "13公众号|03黄色手机",
    "13公众号|04吴学安",
]

folder_names = [
    "第1组_主号诗雨学姐",
    "第2组_副号1学生视角",
    "第3组_副号2干货速记",
    "第4组_副号3避坑吐槽",
    "第5组_副号4考点总结",
    "第6组_副号5考前冲刺",
]

def make_txt(title, body, topics, account):
    return f"标题：{title}\n\n正文：\n{body}\n\n话题：{topics}\n\n时间：\n\n账号：{account}\n"

base = "./发布文案"
os.makedirs(base, exist_ok=True)

for i, c in enumerate(contents):
    folder = os.path.join(base, folder_names[i])
    os.makedirs(folder, exist_ok=True)

    # 小红书（6组都有）
    xhs_name = xhs_accounts[i].replace("06红书店铺|", "")
    with open(os.path.join(folder, f"2_小红书_{xhs_name}.txt"), "w", encoding="utf-8") as f:
        f.write(make_txt(c["title"], c["body"], c["topics"], xhs_accounts[i]))

    # 抖音（第1-5组）
    if i < 5:
        dy_name = dy_accounts[i].replace("07抖音发作品|", "")
        with open(os.path.join(folder, f"1_抖音_{dy_name}.txt"), "w", encoding="utf-8") as f:
            f.write(make_txt(c["title"], c["body"], c["topics"], dy_accounts[i]))

    # 视频号（6组都有）
    sp_name = sp_accounts[i].replace("04视频号|", "")
    with open(os.path.join(folder, f"4_视频号_{sp_name}.txt"), "w", encoding="utf-8") as f:
        f.write(make_txt(c["title"], c["body"], c["topics"], sp_accounts[i]))

    # 公众号（第1-4组）
    if i < 4:
        gzh_name = gzh_accounts[i].replace("13公众号|", "")
        with open(os.path.join(folder, f"13_公众号_{gzh_name}.txt"), "w", encoding="utf-8") as f:
            f.write(make_txt(c["title"], c["body"], c["topics"], gzh_accounts[i]))

# 打包zip
with zipfile.ZipFile("发布文案.zip", "w", zipfile.ZIP_DEFLATED) as zf:
    for root, dirs, files in os.walk(base):
        for file in sorted(files):
            fp = os.path.join(root, file)
            zf.write(fp, os.path.relpath(fp, base))
```

# 自媒体自动发布脚本

Mac 上自动发布内容到小红书、抖音、视频号、公众号的 Python 脚本集合，基于新榜小豆芽。

---

## 脚本文件说明

| 文件 | 说明 |
|------|------|
| `main_publish.py` | 总控脚本，自动识别平台，按顺序调用各平台脚本 |
| `auto_publish.py` | 小红书 / 抖音发布脚本（通过新榜小豆芽） |
| `video_publish.py` | 视频号图文发布脚本 |
| `wechat_publish.py` | 公众号图文发布脚本 |

---

## 运行环境要求

- Mac（Apple Silicon 或 Intel）
- Python 3.9+（系统自带）
- 新榜小豆芽 App（已登录账号）
- 已安装 Pillow、opencv-python、numpy（用于图像识别）

安装依赖：
```bash
/Library/Developer/CommandLineTools/usr/bin/python3 -m pip install Pillow opencv-python numpy
```

---

## 使用前准备

### 1. 辅助功能权限
系统设置 → 隐私与安全性 → 辅助功能，添加「终端」和「Python3」并开启。

### 2. 桌面文件
以下文件需放在桌面：
- `main_publish.py`
- `auto_publish.py`
- `video_publish.py`
- `wechat_publish.py`
- `sync_button_template.png`（同步至右侧按钮截图，用于图像识别）

## txt 文案格式

```
标题：这里写标题（不超过20字）
正文：这里写正文内容（不超过350字，含emoji）
话题：#话题1 #话题2 #话题3
时间：
账号：06红书店铺|粉色手机
```

### 账号字段格式说明

| 平台 | 格式 | 示例 |
|------|------|------|
| 小红书 | `06红书店铺\|账号名` | `06红书店铺\|粉色手机` |
| 抖音 | `07抖音发作品\|账号名` | `07抖音发作品\|01蓝色` |
| 视频号 | `04视频号\|账号名` | `04视频号\|01主账号黄色手机` |
| 公众号 | `13公众号\|账号名` | `13公众号\|01蓝色密码` |

---

## 发布顺序

同一文件夹内多个 txt 的发布顺序：**抖音 → 小红书 → 视频号 → 公众号**

文件命名建议：
- `1抖音版_账号名.txt`
- `2小红书版_账号名.txt`
- `3视频号版_账号名.txt`
- `4公众号版_账号名.txt`

---

## 运行命令

```bash
/Library/Developer/CommandLineTools/usr/bin/python3 ~/Desktop/main_publish.py
```

## 各平台发布流程说明

### 小红书 / 抖音（auto_publish.py）

1. 第一次：打开小豆芽 → 全屏 → 点一键发布
2. 每次：点一键发布 → 点图片发布 → 清空 → 填标题 → 填正文 → 上传图片 → 选账号 → 同步至右侧 → 一键发布 → 等60秒 → 发布至平台 → 等60秒 → 关闭tab → 收尾

**等待时间：**
- 发布至平台前：60秒
- 发布至平台后：60秒
- 篇间隔：30秒

### 视频号（video_publish.py）

每次：多开面板 → 04视频号 → 选账号（等50秒）→ 内容管理 → 图文（等3秒）→ 右滑 → 发表图文 → 音乐（等3秒移动）→ 链接→商品（01/02账号才挂）→ 填标题 → 填描述 → 上传图片（等30秒）→ 滚动到底部 → 发表（等30秒）→ 关闭网页 → 点04视频号（等20秒）

### 公众号（wechat_publish.py）

每次：多开面板 → 13公众号 → 选账号（等30秒）→ 贴图（等10秒）→ 填标题 → 填正文 → 上传图片（等30秒）→ 滚动到底部 → 链接→小店商品→搜索「会计漫画笔记」（等5秒）→ 选第一个 → 插入 → 发表 → 确认发表（等10秒）→ 继续发表（等35秒）→ 关闭公众号×2 → 点13公众号

## 注意事项

1. 运行脚本时不要碰鼠标和键盘
2. 保持小豆芽窗口位置固定，坐标才准确
3. 电脑不能锁屏（关闭自动锁屏）
4. `sync_button_template.png` 必须放在桌面
5. 坐标是针对特定屏幕尺寸校准的，换电脑需重新采集

# 【真实人物 + 小红书学习图文风】Codex 作图风格提示词

适用于：初级会计 / 中级会计 / CPA / 考公 / 学习规划 / 焦虑安慰 / 备考建议 / 经验分享 / 学习节奏类内容。

核心特点：真实女生人物 + 清爽手写笔记排版 + 小红书收藏感 + 文字清晰 + 情绪陪伴感。

---

## 一、风格总定义

这套图的核心不是纯插画，也不是纯海报，而是：

**真实感学习场景照片 + 手写感信息排版 + 小红书收藏型图文**

整体效果要像：
- 一个真实备考女生在书桌前学习
- 旁边叠加清晰的笔记型文字信息
- 有温柔、治愈、陪伴感
- 适合发小红书、朋友圈、图文账号
- 看起来真实、干净、耐看、容易收藏

---

可直接给 Codex / 生图模型使用：

- 3:4 竖版
- 真实年轻女生

- 小红书图文风

- 桌面有教材、笔记本、便签、计算器、马克杯

## 三、人物设定规则

### 1. 人物类型

默认人物设定：
- 年轻女生
- 年龄感约 20—28 岁
- 气质：学生感、学姐感、干净温柔、真实自然
- 不要网红浓妆脸
- 不要夸张摆拍
- 不要职业模特感太强
- 要有“真实备考的人”的感觉

### 2. 外形建议

- 发型：丸子头、低马尾、自然扎发、微乱碎发
- 穿搭：浅灰卫衣、米白卫衣、奶油色针织、浅色家居学习装
- 表情：认真、安静、微焦虑、思考中、轻松、鼓励感
- 动作：写字、看笔记、扶脸思考、拿手机/平板、拿计划本、翻书、展示清单页

### 3. 人物比例

- 人物一般放在画面右侧或右下区域
- 占画面约 35%—50%
- 不要过大挤压文字区域
- 文字和人物要并存，人物服务内容，不抢标题

## 四、场景设定规则

### 默认场景

- 室内书桌学习场景
- 浅色干净房间

- 打开的笔记本 / 练习册
- 中性笔
- 便签纸
- 计算器
- 马克杯
- 计划表 / 清单页
- 手机 / 平板
- 小台历 / 月历

### 场景氛围

- 安静
- 稳定
- 温柔
- 有陪伴感
- 有真实学习气息
- 不要杂乱
- 不要过多复杂背景家具
- 不要咖啡馆噪音感太强

## 五、版式规则

这套风格的本质是：

**左侧文字信息区 + 右侧真实人物学习场景**

或：

**顶部大标题 + 左侧文字卡片 + 右侧人物/桌面**

### 版式 A｜封面型

适合第一页 / 首页。

结构：
- 顶部超大标题
- 中部副标题 / 重点句
- 左侧或左下信息摘要
- 右侧真实人物
- 右上角页码，如 1/5、1/6

适用：封面、主题总述、情绪开场。

### 版式 B｜观点拆解型

结构：
- 顶部大标题
- 左侧纵向 3—4 个内容卡片
- 右侧人物写字 / 看书 / 展示计划本
- 底部一句总结条

适用：“3条建议”“3个优势”“4个原因”“常见问题拆解”。

### 版式 C｜节奏规划型

结构：
- 顶部大标题
- 左侧时间轴 / 月度进度 / 阶段卡片
- 右侧人物学习场景
- 底部执行建议

适用：学习计划、备考节奏、时间安排、分阶段复习建议。

### 版式 D｜清单展示型

结构：
- 标题
- 左侧 checklist / bullet list
- 人物手中拿着计划表 / 复盘本 / 章节框架
- 底部鼓励语

适用：复盘页、打卡页、清单页、做题策略页。

## 六、文字风格规则

### 1. 标题风格

标题必须有：
- 超大号、黑色、粗手写感字体
- 像手写笔记标题
- 不要标准印刷体
- 不要太细
- 不要花体
- 不要毛笔书法感

标题处理方式：
- 主体字：黑色粗手写
- 关键词：粉色 / 珊瑚红 / 玫粉重点强调
- 关键词可配：下划线、波浪线、彩色描边、浅色荧光底

示例：
- 现在开始备考2027年初级会计，**比别人早半年**
- 初级会计**没过怎么办**？
- 建议① 先找**问题**
- 优势③ 做题量自然多，考场发挥**更稳**

### 2. 副标题风格

- 副标题通常放在浅蓝/浅粉底条上
- 用清晰黑字
- 短句为主
- 控制在 8—20 字以内

示例：
- 早开始，不是卷，是聪明备考
- 每天1小时，也能稳稳推进
- 找到一起备考的人

### 3. 正文排版

正文一定要：
- 清晰、工整、可读
- 字号不要过小
- 左对齐
- 一块内容不要太长
- 尽量拆成卡片式信息块

正文内容卡一般包含：
- 序号圆点，如 1 / 2 / 3 / 4
- 一句短标题
- 2—4 行说明

### 4. 重点强调规则

重点词不能全靠黑字，要做层级。

重点词可用颜色：
- 玫粉
- 珊瑚粉
- 浅红
- 湖蓝
- 明黄底高亮
- 少量浅紫
- 少量橙色

重点处理方式：
- 彩色关键词
- 荧光笔底色
- 下划线
- 波浪线
- 手绘圈画
- 贴纸底框
- 数字放大

重点内容优先高亮：
- 时间：12个月 / 6月26日 / 1天20页
- 数字：15%—20% / 3条建议 / 3个优势
- 结论：更稳 / 更有方向 / 早半年
- 鼓励语：别怕 / 慢一点也没关系 / 不是你不适合

## 七、色彩系统

### 基础配色

整体必须清爽、柔和、浅色、耐看。

背景色：
- 米白
- 浅奶油
- 浅杏白
- 极浅暖灰白

重点色：
- 玫粉
- 珊瑚粉
- 淡粉红
- 湖蓝
- 浅蓝
- 明黄色（少量）
- 奶油黄
- 薄荷绿（少量）
- 浅紫（少量辅助）

正文字色：
- 深黑
- 深墨黑
- 深灰黑

### 配色原则

- 背景永远浅
- 正文永远深色
- 彩色主要用于关键词和贴纸
- 不要大面积高饱和
- 不要红蓝大对撞
- 不要荧光色大片铺底
- 要像“小红书可收藏学习图”，不是电商促销海报

## 九、常见页面类型模板

### 1. 封面页

用途：标题页、情绪切入页。

特点：
- 标题最大
- 人物状态明确
- 关键词高亮明显
- 文字不要太满

### 2. 建议页 / 优势页 / 原因页

用途：“3条建议”“3个真实优势”“为什么”“怎么做”。

特点：
- 3—4 个卡片分点
- 左文字右人物
- 底部一句总结

### 3. 节奏规划页

用途：时间安排、月度规划、复习阶段。

特点：
- 时间轴 / 分阶段卡片
- 有清晰月份
- 有执行动作词
- 人物继续学习场景

### 4. 收尾鼓励页

用途：结尾、情绪安慰、互动引导。

特点：
- 语气温柔
- 少一点知识，多一点陪伴
- 可出现：
  - 别怕，慢一点也没关系
  - 成绩出来记得告诉我
  - 我们一起

## 十、内容语气要求

这套风格不只是视觉，还要匹配文案语气。

语气关键词：
- 学姐感
- 陪伴感
- 真诚
- 不鸡汤过度
- 不贩卖焦虑
- 不高高在上
- 有经验但不训人
- 温柔鼓励
- 说人话

常见语气模式：
- 其实完全没必要。
- 这种感觉很正常。
- 先记住一句话。
- 现在开始，不是卷，是聪明备考。
- 别急着否定自己。
- 早开始的人，考场上的底气真的不一样。

## 第一章 税法总论

### 核心考点

**税法原则（4大基本原则）**
- 税收法定原则（核心）：纳税人、征税对象、税率必须由法律规定
- 税收公平原则：横向公平（能力相同，税负相同）+ 纵向公平
- 税收效率原则：经济效率 + 行政效率
- 实质课税原则：按实质而非形式

**税法适用原则（6个）**
1. 法律优位原则
2. 法律不溯及既往原则
3. 新法优于旧法原则
4. 特别法优于普通法原则
5. 实体从旧、程序从新原则
6. 程序优于实体原则（税收争讼时适用）

**税法要素（11个）**
总则、纳税义务人、征税对象、税目、税率、纳税环节、纳税期限、纳税地点、减税免税、罚则、附则

**税率类型**
- 比例税率：增值税、企业所得税（单一/差别/幅度）
- 超额累进税率：个人所得税综合所得、经营所得
- 全额累进税率（目前已不采用）
- 定额税率：城镇土地使用税、车船税
- 超率累进税率：土地增值税

**我国税收体系（中央税/地方税/共享税）**
- 中央税：消费税、关税、车辆购置税
- 地方税：房产税、契税、土地增值税、城镇土地使用税、耕地占用税、车船税
- 共享税：增值税（中央50%/地方50%）、企业所得税、个人所得税

### 高频考题方向
- 判断税法原则的适用
- 区分税法要素
- 判断税种归属（中央/地方/共享）

## 第二章 增值税法 ⭐⭐⭐（最重要）

> 2026年重大变化：《增值税法》2024年12月25日通过，2026年1月1日施行，废止《增值税暂行条例》
> 《增值税法实施条例》2025年12月19日通过，2026年1月1日施行

### 第一节 征税范围

**应税交易构成要件（3个）**
1. 发生销售行为（有偿转让货物所有权/提供服务/转让无形资产使用权/转让不动产所有权）
2. 销售发生在境内
3. 交易标的属于货物、服务、无形资产、不动产

**"境内"判定**
- 销售货物：货物起运地或所在地在境内
- 销售不动产/租赁自然资源使用权：不动产/自然资源所在地在境内
- 销售金融商品：金融商品在境内发行，或销售方为境内单位和个人
- 销售服务/无形资产：服务/无形资产在境内消费，或销售方为境内单位和个人

**货物范围**：有形动产、电力、热力、气体等

**服务范围（6大类）**
1. 交通运输服务（陆路/水路/航空/管道）
2. 邮政服务
3. 电信服务（基础电信/增值电信）
4. 建筑服务（工程/安装/修缮/装饰/其他建筑服务）
5. 金融服务（贷款/直接收费金融/保险/金融商品转让）
6. 生产生活服务（研发技术/信息技术/文化创意/物流辅助/租赁/鉴证咨询/广播影视/商务辅助/其他）

**视同销售（须缴增值税的情形）**
- 将货物用于集体福利或个人消费
- 将货物无偿赠送他人（但与其他单位联合公益活动赠送除外）
- 将货物用于非增值税应税项目
- 将自产/委托加工货物用于投资、分配股利、偿债
- 将不动产/无形资产无偿转让（特定公益除外）

**不征增值税情形**
- 行政单位收取的政府性基金/行政事业性收费
- 存款利息
- 依法不征税的其他情形

### 第二节 纳税人和扣缴义务人

**一般纳税人与小规模纳税人**

| 项目 | 一般纳税人 | 小规模纳税人 |
|------|-----------|------------|
| 年销售额标准 | >500万元 | ≤500万元 |
| 计税方法 | 一般计税法 | 简易计税法 |
| 进项抵扣 | 可以抵扣 | 不得抵扣 |
| 发票 | 可开专票 | 限制开专票 |

**扣缴义务人**：境外单位/个人在境内销售服务/无形资产/不动产，境内购买方为扣缴义务人

### 第三节 税率

**基本税率**

| 税率 | 适用范围 |
|------|---------|
| 13% | 销售货物、加工修理修配劳务、有形动产租赁服务、进口货物（一般情况）|
| 9% | 交通运输服务、邮政服务、基础电信服务、建筑服务、不动产销售/租赁、农产品等 |
| 6% | 金融服务、增值电信服务、生产生活服务、无形资产（土地使用权/专利等）|
| 0% | 出口货物、跨境服务（符合条件）|

**征收率（小规模纳税人）**
- 一般：3%（目前优惠政策：1%）
- 特定：5%（不动产出租、销售不动产、提供劳务派遣/安保服务等选择简易计税）

### 第四节 一般计税方法应纳税额

**基本公式**
```
应纳税额 = 当期销项税额 - 当期进项税额
```

**销项税额**
```
销项税额 = 销售额 × 税率
销售额（不含税）= 含税价格 ÷ (1 + 税率)
```

**销售额的特殊情况**
- 价格明显偏低且无正当理由：按市场价核定
- 混合销售：从主销售行为适用税率
- 兼营：分别核算，不分别核算的从高适用税率
- 折扣销售：同一发票注明折扣额，可扣除折扣；另开发票的折扣，不得扣减
- 销售返还/补贴：按实际收取金额计税
- 包装物押金：一年内未退还的，并入销售额征税（酒类产品押金直接并入）

**进项税额（可抵扣）**
- 增值税专用发票注明的税额
- 海关完税凭证注明的税额
- 农产品收购发票：按买价×9%计算
- 旅客运输费用：铁路票9%，航空/公路/水路票3%
- 带薪发票（水电费等）按规定比例分摊

**进项税额不得抵扣情形**
1. 用于简易计税项目、免税项目、集体福利/个人消费的购进
2. 非正常损失的购进货物及相关服务
3. 非正常损失在产品、产成品（所耗购进货物/服务/不动产）
4. 购进的旅客运输服务、餐饮服务、居民日常服务、娱乐服务
5. 以贷款服务取得的进项税额

**进项税额转出**：原可抵扣但后改变用途，须转出

### 第五节 简易计税方法

**适用情形**
- 小规模纳税人
- 一般纳税人的特定业务（选择适用）：
  - 销售自己使用过的固定资产
  - 销售旧货
  - 一般纳税人提供劳务派遣/安保等
  - 建筑企业简易计税项目
  - 不动产销售/租赁（特定情况）

**计算公式**
```
应纳税额 = 销售额 × 征收率
销售额 = 含税销售额 ÷ (1 + 征收率)
```

### 第六节 进口环节增值税

```
组成计税价格 = 关税完税价格 + 关税 + 消费税
应纳增值税 = 组成计税价格 × 税率
```

### 第七节 出口退税

**退税方式**
1. 免退税（生产企业）
2. 免抵退税（生产企业）
3. 免税（特定情况）

**免抵退税计算步骤**
1. 计算当期免抵退税不得免征和抵扣税额
2. 计算当期应纳税额
3. 计算当期免抵退税额
4. 确定当期应退税额和免抵税额

### 第八节 税收优惠

**免税项目（重点）**
- 农业生产者销售自产农产品
- 避孕药品和用具
- 古旧图书
- 直接用于科学研究、科学试验和教学的进口仪器设备
- 外国政府/国际组织无偿援助进口的物资
- 残疾人组织直接进口的残疾人专用品
- 销售自己使用过的物品（个人）
- 医疗机构提供的医疗服务
- 教育劳务（学历教育）
- 托儿所、幼儿园提供的保育和教育服务
- 金融机构农户小额贷款利息收入
- 国家助学贷款利息收入

### 第九节 征收管理

**纳税期限**
- 一般：月/季度（月度：次月1日起15日内申报）
- 进口货物：海关放行后15日内缴纳

**纳税地点**
- 固定业户：向机构所在地申报纳税
- 跨县（市）提供建筑服务：预缴+申报
- 不动产所在地：预缴

## 第三章 消费税法 ⭐⭐

### 核心特点
- 价内税（税款包含在价格中）
- 单一环节征收（一般在生产/进口环节）
- 差别税率（15个税目）

### 纳税人与税目

**15个税目**
1. 烟（卷烟/雪茄烟/烟丝）
2. 酒（白酒/黄酒/啤酒/其他酒）
3. 高档化妆品
4. 贵重首饰及珠宝玉石
5. 鞭炮、焰火
6. 成品油
7. 摩托车
8. 小汽车
9. 高尔夫球及球具
10. 高档手表
11. 游艇
12. 木制一次性筷子
13. 实木地板
14. 电池
15. 涂料

### 计税方法

**从价计征**
```
应纳税额 = 销售额 × 比例税率
```

**从量计征**
```
应纳税额 = 销售数量 × 定额税率
```

**复合计征（白酒、卷烟）**
```
应纳税额 = 销售额 × 比例税率 + 销售数量 × 定额税率
```

### 计税依据的特殊处理

**组成计税价格（自产自用/委托加工/进口）**
```
组成计税价格 = 成本 × (1 + 成本利润率) ÷ (1 - 消费税税率)  [生产/自用]
组成计税价格 = (材料成本 + 加工费) ÷ (1 - 消费税税率)  [委托加工]
组成计税价格 = (关税完税价格 + 关税) ÷ (1 - 消费税税率)  [进口]
```

### 已纳税款的扣除

**外购应税消费品用于继续生产应税消费品**：可扣除已纳消费税
- 烟丝→卷烟，酒精→白酒/黄酒/啤酒，珠宝玉石→首饰，成品油相互加工，高档化妆品
- 公式：应扣除已纳税款 = 当期领用数量 × 单位税额

### 委托加工应税消费品
- 由受托方在交货时代收代缴消费税
- 委托方收回后直接销售：不再缴消费税
- 委托方收回后继续加工：可扣除已纳消费税

### 高频考点
- 白酒：比例税率20% + 定额0.5元/500克（复合计征）
- 卷烟：生产环节56%/36% + 0.003元/支；批发环节11%
- 金银首饰在零售环节征税（其他贵重首饰在生产/进口环节）
- 进口应税消费品：海关代征

## 第四章 企业所得税法 ⭐⭐⭐

### 纳税人

| 类型 | 判断标准 | 纳税义务 |
|------|---------|---------|
| 居民企业 | 注册地/实际管理机构在中国 | 全球征税 |
| 非居民企业（有机构）| 机构在中国，但未全部来源于机构 | 与机构有实际联系的所得 |
| 非居民企业（无机构）| 无机构/机构与所得无联系 | 来源于中国境内所得 |

### 应纳税所得额

```
应纳税所得额 = 收入总额 - 不征税收入 - 免税收入 - 各项扣除 - 允许弥补的以前年度亏损
```

**收入总额**：销售货物收入、提供劳务收入、转让财产收入、股息红利、利息收入、租金收入、特许权使用费收入、接受捐赠收入、其他收入

**不征税收入**：财政拨款、依法收取纳入财政管理的行政事业性收费和政府性基金、国务院规定的其他不征税收入

**免税收入**
- 国债利息收入
- 符合条件的居民企业间股息红利（直接投资且持股≥12个月）
- 在中国境内设立机构的非居民企业从居民企业取得的股息红利（持股≥12个月）
- 符合条件的非营利组织收入

### 扣除项目

**工资薪金**：合理工资可据实扣除

**三项经费（工资为基数）**
- 职工福利费：14%以内
- 工会经费：2%以内
- 职工教育经费：8%以内（超出可结转）

**业务招待费**：发生额60%与当年销售（营业）收入5‰，取较小值

**广告费和业务宣传费**：当年销售（营业）收入15%以内（超出可结转）；化妆品/制药/饮料（不含酒）企业：30%

**公益性捐赠**：年利润12%以内（超出可结转3年）

**利息费用**
- 向金融机构：全额扣除
- 向非金融机构/关联方：不超过金融机构同期同类贷款利率计算的数额

**不得扣除项目**
- 资本性支出（应计入资产成本）
- 税收滞纳金、罚款、罚金
- 赞助支出（非公益性捐赠）
- 未经批准提取的准备金
- 与收入无关的支出

### 资产的税务处理

**固定资产折旧**
- 一般折旧年限：房屋建筑物20年，飞机/火车/轮船/机器10年，工器具/家具5年，电子设备3年
- 计提方法：直线法（加速折旧需报批）
- 不计提折旧：未投入使用的/无形资产

**无形资产摊销**：不少于10年（取得时已约定使用年限的按约定）

**开办费**：选择一次性扣除或3年内摊销

### 税率

| 情况 | 税率 |
|------|------|
| 一般居民企业 | 25% |
| 小型微利企业（年应纳税所得额≤300万） | 5%（25万以内）/10%（25-300万）|
| 高新技术企业 | 15% |
| 技术先进型服务企业 | 15% |
| 非居民企业（源泉扣缴）| 10%（协定减免后可能更低）|

### 税收优惠

**免税**
- 农/林/牧/渔业项目
- 国家重点扶持的公共基础设施项目（3免3减半）
- 符合条件的环境保护、节能节水项目（3免3减半）
- 符合条件的技术转让所得（500万以内免税，超出50%减征）

**减税**
- 小型微利企业
- 高新技术企业15%

**加计扣除**
- 研发费用：一般企业100%加计（即按200%扣除）
- 残疾人工资：100%加计

### 应纳税额

```
应纳税额 = 应纳税所得额 × 税率 - 减免税额 - 抵免税额
```

**境外已纳税款抵免**：分国不分项，用抵免限额法
```
抵免限额 = 境内外应纳税总额 × 境外所得 ÷ 境内外所得总额
```

### 亏损弥补
- 一般企业：亏损向后弥补5年
- 高新技术企业/科技型中小企业：可弥补10年

### 征收管理
- 年度预缴：按月或按季
- 年度申报：5个月内（4月30日前）

## 第五章 个人所得税法 ⭐⭐⭐

### 纳税人

| 类型 | 判断 | 纳税义务 |
|------|------|---------|
| 居民个人 | 住所在中国，或居住≥183天 | 全球征税 |
| 非居民个人 | 无住所且居住<183天 | 仅境内所得 |

### 所得类型（9类）

**综合所得（4项，超额累进税率）**
1. 工资薪金所得
2. 劳务报酬所得
3. 稿酬所得
4. 特许权使用费所得

**分类所得（5项）**
5. 经营所得（5级超额累进）
6. 利息股息红利所得（20%）
7. 财产租赁所得（20%，月≤4000扣800；月>4000扣20%）
8. 财产转让所得（20%）
9. 偶然所得（20%）

### 综合所得计算

**年度汇算清缴**
```
应纳税所得额 = 收入总额 - 免税收入 - 减除费用(6万) - 专项扣除 - 专项附加扣除 - 依法确定的其他扣除
```

**税率（7级超额累进）**

| 级数 | 全年应纳税所得额 | 税率 | 速算扣除数 |
|-----|---------------|------|---------|
| 1 | ≤36000 | 3% | 0 |
| 2 | 36001-144000 | 10% | 2520 |
| 3 | 144001-300000 | 20% | 16920 |
| 4 | 300001-420000 | 25% | 31920 |
| 5 | 420001-660000 | 30% | 52920 |
| 6 | 660001-960000 | 35% | 85920 |
| 7 | >960000 | 45% | 181920 |

**专项扣除**（按实扣除）
- 基本养老保险、基本医疗保险、失业保险、住房公积金

**专项附加扣除（重点）**

| 项目 | 扣除标准 |
|------|---------|
| 子女教育 | 每孩每月2000元（父母各1000或一方全扣） |
| 继续教育 | 学历教育400元/月；职业资格技能证书3600元/年 |
| 大病医疗 | 年度自付超1.5万以上部分，上限8万 |
| 住房贷款利息 | 首套房1000元/月，最长240个月 |
| 住房租金 | 1500/1100/800元/月（按城市分） |
| 赡养老人 | 独生子女2000元/月；非独生子女不超2000元/月分摊 |
| 婴幼儿照护 | 3岁以下婴幼儿，每孩每月2000元 |

### 劳务报酬的预扣预缴

```
预扣预缴应纳税所得额 = 每次劳务报酬 × (1-20%) （>4000时）
或每次劳务报酬 - 800 （≤4000时）
```

**劳务报酬适用税率（预扣预缴）**

| 应纳税所得额 | 预扣率 | 速算扣除数 |
|------------|--------|---------|
| ≤20000 | 20% | 0 |
| 20001-50000 | 30% | 2000 |
| >50000 | 40% | 7000 |

**稿酬折扣**：应纳税所得额再×70%

### 经营所得（5级超额累进）

| 级数 | 全年应纳税所得额 | 税率 | 速算扣除数 |
|-----|---------------|------|---------|
| 1 | ≤30000 | 5% | 0 |
| 2 | 30001-90000 | 10% | 1500 |
| 3 | 90001-300000 | 20% | 10500 |
| 4 | 300001-500000 | 30% | 40500 |
| 5 | >500000 | 35% | 65500 |

### 免税项目（重点）
- 国债利息
- 省级以上奖金（国家级/省级）
- 福利费、抚恤金、救济金
- 保险赔款
- 军人转业费
- 离退休人员退休金（国家统一标准）
- 外籍人员住房补贴、语言培训费、子女教育费（凭票扣除，合理部分）

### 股权激励与股票期权
- 行权时：工资薪金所得 = （行权价 - 授权价）× 行权数量
- 适用优惠：满足条件可单独按综合所得税率，不并入当年综合所得

### 境外所得
- 来源地（境外）已缴税：抵免，但不超过抵免限额

## 第六章 城市维护建设税法和烟叶税法

### 城市维护建设税

**计税依据**：实际缴纳的增值税、消费税税额

**税率（地区差别比例税率）**
- 市区：7%
- 县城、镇：5%
- 其他：1%

**附加**
- 教育费附加：3%（增值税+消费税之和×3%）
- 地方教育附加：2%

**特殊规则**
- 不适用于进口货物/境外服务（进口环节的增值税、消费税不征城建税）
- 出口退还增值税/消费税，同时退还城建税
- 实际纳税地点在市区/县城/镇以外的纳税人，按"其他"1%计征

## 第七章 关税法和船舶吨税法

### 关税

**完税价格**
- 进口：成交价格为基础（含运费+保险费到CIF价）
- 出口：成交价格（FOB价）

**税率类型**
- 最惠国税率（MFN）
- 协定税率（FTA等）
- 普通税率
- 特别关税（反倾销税、反补贴税、保障措施税）

**应纳税额**
```
从价：应纳税额 = 完税价格 × 税率
从量：应纳税额 = 货物数量 × 单位税额
复合：两者相加
```

**免税情形**
- 价值50元以下的礼品
- 外国政府、国际组织无偿赠送的物资
- 暂时进出口货物（保证金担保后免税）
- 书籍/报刊/杂志等出版物（特定条件）

**关税保全**：海关可对纳税义务人采取强制措施

---

## 第八章 资源税法和环境保护税法

### 资源税

**纳税人**：开采矿产资源或生产盐的单位和个人

**税率**
- 从价：石油/天然气 6%；煤炭 2%-10%
- 从量：盐（从量计征）

**计税依据**
- 从价：销售额（不含增值税）
- 从量：销售量/自用量

**减免优惠**
- 开采中因开采损失的部分
- 城镇污水集中处理、生活垃圾集中处理的

### 环境保护税

**应税污染物**：大气污染物、水污染物、固体废物、噪声

**计税依据**：污染物排放量（当量数）

**应纳税额**
```
大气/水：污染当量数 × 适用税额
固体废物：固体废物排放量 × 适用税额
噪声：超标分贝对应税额
```

**不征税情形**
- 企业排放的应税污染物浓度低于国家/地方标准30%：减25%
- 低于50%：减50%
- 征收排污费的不再征环保税（同一污染物）
- 农业生产排放的应税污染物
- 达标排放的城镇污水集中处理、生活垃圾集中处理设施

---

## 第九章 城镇土地使用税法和耕地占用税法

### 城镇土地使用税

**纳税人**：拥有土地使用权的单位和个人（以土地使用权证为准）

**计税依据**：实际占用土地面积（平方米）

**税率**：定额税率（各地不同，大城市0.5-10元/㎡/年）

**免税情形**
- 国家机关、军队、人民团体
- 由国家财政部门拨付事业经费的单位
- 宗教寺庙、公园、名胜古迹
- 市政街道、广场、绿化地带等公共用地
- 农村土地（农民集体所有土地，另行规定）
- 个人所有的居住房屋及院落用地

### 耕地占用税

**纳税人**：占用耕地建设建筑物、构筑物或从事非农业建设的单位和个人

**计税依据**：实际占用耕地面积

**税率**：按地区差别，10-50元/㎡（一次性征收）

## 第十章 房产税法、契税法和土地增值税法

### 房产税

**纳税人**：在城市、县城、建制镇和工矿区范围内，房屋产权所有人

**计税依据和税率**
- 从价：房产原值×（1-10%~30%）× 1.2%/年
- 从租：租金收入 × 12%（个人出租住房4%）

**免税情形**
- 国家机关、人民团体、军队自用房产
- 由国家财政部门拨付事业经费单位的自用房产
- 宗教寺庙、公园、名胜古迹的自用房产
- 个人所有的非营业用的房产（住宅）
- 纳税人建造用于出售的商品房（未销售前）

### 契税

**纳税人**：土地使用权、房屋所有权转移时，受让方

**税率**：3%-5%（地方确定，一般3%；2024年起首套及1套换购均为1%，有的为1.5%-3%不等）

**计税依据**：成交价格

**免税情形**
- 国家机关、事业单位承受国家划拨土地用于办公
- 农村居民承受本集体土地（特定用途）
- 婚姻关系存续期间夫妻间房产分割
- 法定继承人继承土地、房屋权属

### 土地增值税

**纳税人**：转让国有土地使用权、地上建筑物及其附着物并取得收入的单位和个人

**增值额**：转让收入 - 扣除项目金额

**扣除项目（5类）**
1. 取得土地使用权支付的金额
2. 开发土地的成本、费用（含20%以内加计扣除）
3. 新建房的建造成本、费用（含20%以内加计扣除）
4. 与转让有关的税金（营业税/城建税/教育附加）
5. 旧房及建筑物的评估价格

**税率（超率累进，4档）**

| 增值率 | 税率 | 速算扣除系数 |
|--------|------|------------|
| ≤50% | 30% | 0 |
| 50%-100% | 40% | 5% |
| 100%-200% | 50% | 15% |
| >200% | 60% | 35% |

**免征情形**
- 纳税人建造普通标准住宅出售，增值额未超过扣除项目金额20%
- 因国家建设需要依法征用、收回的房地产
- 个人住所在规定居住年限后转让

**清算条件**
- 达到完工条件
- 预售证在2年内未销售超85%
- 主管税务机关认为有必要

## 第十一章 车辆购置税法、车船税法和印花税法

### 车辆购置税

**纳税人**：购置（购买/进口/受赠/自产自用等）应税车辆的单位和个人

**应税车辆**：汽车、摩托车、电车、挂车、农用运输车

**税率**：10%

**计税依据**
- 购买：不含增值税的购车价格（含各种价外费用）
- 进口：关税完税价格+关税+消费税
- 受赠/中奖/自产自用：最低计税价格（参考同型号）

**免税**：军警车、大使馆/领事馆用车、残疾人专用车、农用车辆（特定）

### 车船税

**纳税人**：在境内持有车辆和船舶的单位和个人（以登记机关为准）

**税率**：定额税率（各省不同）

**船舶**：净吨位计税；机动船、拖船计载重吨位

**免税**：捕捞船/养殖船、军事/警察用车船、非机动渔船等

### 印花税

**纳税人**：书立应税凭证的单位和个人

**应税凭证（15类）**
主要：合同（包括购销合同、加工承揽合同、建设工程合同、运输合同、技术合同、租赁合同、保险合同、借款合同）、产权转移书据（包括土地、房屋）、营业账簿等

**税率**

| 凭证类型 | 税率 |
|---------|------|
| 购销合同 | 0.03‰ |
| 建设工程合同 | 0.03‰ |
| 加工承揽/科技研究 | 0.03‰ |
| 运输合同 | 0.03‰ |
| 技术合同（技术转让） | 0.03‰ |
| 租赁合同 | 1‰ |
| 借款合同（金融机构） | 0.05‰ |
| 保险合同 | 0.1‰ |
| 产权转移书据 | 0.05‰（股票：1‰） |
| 营业账簿 | 0.025‰ |

**免税**：农牧业保险合同、军事协议、无偿赠与合同（公益救灾）、注册资本小规模等

## 第十二章 国际税收税务管理实务

### 国际税收协定

**作用**：消除双重征税、防止偷逃税、税收无差别待遇

**避免双重征税方法**
- 免税法：居住国对来源国已税所得免税
- 抵免法（直接+间接）：居住国允许用已纳外国税款抵减

**常设机构**（PE）
- 有：税收协定允许来源国征税
- 无：来源国一般不征税（营业利润）

**BEPS行动计划（税基侵蚀和利润转移）**
- 中国已签署BEPS多边公约（2022年9月生效）
- 主要内容：防止滥用税收协定、阻止人为规避常设机构、提高透明度

### 非居民企业

**预提所得税（10%）**
- 对象：支付给非居民企业的股息、利息、租金、特许权使用费、财产转让所得等
- 扣缴：支付方为扣缴义务人

**境外所得税收管理**
- 居民企业境外所得汇回或通过利润分配：需申报纳税
- 受控外国公司（CFC）：条件满足须视同分配处理

## 第十三章 税收征收管理法

### 核心制度

**税务登记**：开业→30日内；变更→30日内；注销→注销前

**纳税申报**：正常情况月（季）度申报，年度申报

**税款征收方式**
1. 查账征收
2. 定期定额征收
3. 核定征收（资料不齐或账务混乱时）
4. 委托代征

**税款滞纳金**：0.05%/日，从滞纳之日起

**税收保全和强制执行**
- 保全：可扣押/查封财物、冻结存款
- 强制执行：扣缴银行存款、拍卖扣押物品

**纳税担保**：纳税保证（人保）+ 纳税抵押/质押（物保）

### 税务检查

**检查权**：查账、查库、查场所

**追征期**
- 一般：3年
- 特殊（有转移财产/逃避追缴等情节）：5年
- 偷税/骗税：无限期

### 法律责任

**行政责任**
- 违反税务登记管理：最高1万元罚款
- 不申报或申报不实：最高3倍罚款
- 偷税：50%-5倍罚款 + 追缴税款

**刑事责任**
- 逃税罪：3年以下/3-7年有期徒刑
- 骗取出口退税罪：5年以下/5-10年/10年以上
- 抗税罪：3年以下/3-7年有期徒刑

---

## 第十四章 税务行政法制

### 税务行政处罚

**种类**：罚款、没收违法所得、停止出口退税权

**处罚程序**
- 简易程序：罚款500元以下（个人）/10000元以下（单位），当场做出
- 一般程序：调查取证→告知→听证（>100000元须听证）→决定

**不予处罚**：违法行为轻微并及时纠正；初次违法且危害后果较小（主动改正）

### 税务行政复议

**受理机关**：上一级税务机关或本级税务机关（视情况）

**申请期限**：知道或应当知道之日起60日内

**特殊规则**：对税务机关的具体征税行为不服，必须先复议再诉讼（不得直接起诉）

**复议决定**：60日内做出

### 税务行政诉讼

**管辖**：中级人民法院管辖或基层法院

**起诉期限**：收到复议决定书15日内提起

**举证责任**：税务机关承担举证责任（行政诉讼原则）

## 高频考点总结

| 税种 | 最高频考点 | 难度 |
|------|---------|------|
| 增值税 | 进项税额抵扣/销项税额计算/视同销售 | ⭐⭐⭐ |
| 消费税 | 组成计税价格/委托加工/白酒复合计征 | ⭐⭐⭐ |
| 企业所得税 | 费用扣除限额/固定资产折旧/税收优惠 | ⭐⭐⭐ |
| 个人所得税 | 综合所得计算/专项附加扣除/劳务报酬 | ⭐⭐⭐ |
| 土地增值税 | 增值额计算/四级超率累进税率 | ⭐⭐ |
| 印花税 | 税目判断/税率记忆 | ⭐⭐ |
| 关税 | 完税价格/进口组价 | ⭐⭐ |
| 城建税 | 随增/消缴纳/不适用进口 | ⭐ |

## 常见易错点

1. **增值税**：餐饮服务、娱乐服务、居民日常服务、旅客运输进项不得抵扣
2. **消费税**：金银首饰在零售环节才征消费税（其他贵重首饰在生产/进口）
3. **企业所得税**：居民企业间股息红利免税须持股≥12个月
4. **个人所得税**：稿酬所得还要再×70%才是应纳税所得额
5. **关税**：进口CIF完税，出口FOB完税
6. **城建税**：进口不征；出口退税同步退
7. **土地增值税**：普通住宅增值率≤20%免税
8. **印花税**：借款合同只对金融机构的贷款征税（企业间借款免税）

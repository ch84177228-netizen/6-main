## 第一章 总论（低频，3分左右）

### 核心考点

**会计的概念**
- 会计是以货币为主要计量单位，反映和监督经济活动的一种经济管理工作

**会计的职能**
- 核算职能（基本）：事中进行，连续、系统、全面
- 监督职能（重要）：事前、事中、事后
- 两者关系：核算是监督的基础，监督是核算的保证

**会计核算的基本假设（4个）**

| 假设 | 内容 | 意义 |
|------|------|------|
| 会计主体 | 区分企业与业主的经济活动 | 空间范围 |
| 持续经营 | 可预见的未来继续存在 | 确定会计方法 |
| 会计分期 | 分为年度、半年度、季度、月度 | 权责发生制基础 |
| 货币计量 | 货币为统一计量单位 | 具有局限性 |

**会计信息质量要求（8个）**
1. 可靠性（首要）
2. 相关性
3. 可理解性
4. 可比性
5. 实质重于形式
6. 重要性
7. 谨慎性（不高估资产，不低估负债）
8. 及时性

**权责发生制**：凡是当期已实现的收入和已发生的费用，不论是否收付现金，均应确认为当期收入和费用

## 第二章 会计基础（高频，重点章）⭐⭐⭐

### 第一节 会计要素与会计等式

**六大会计要素**

| 要素 | 类型 | 特征 |
|------|------|------|
| 资产 | 资产负债表 | 过去事项形成，现在控制，未来流入经济利益 |
| 负债 | 资产负债表 | 过去事项形成，现在义务，未来流出经济利益 |
| 所有者权益 | 资产负债表 | 资产减去负债后的余额 |
| 收入 | 利润表 | 日常活动中形成的经济利益流入 |
| 费用 | 利润表 | 日常活动中发生的经济利益流出 |
| 利润 | 利润表 | 收入减去费用后的净额（含直接计入利润的利得/损失）|

**会计等式**
- 基本：资产 = 负债 + 所有者权益
- 扩展：资产 = 负债 + 所有者权益 + (收入 - 费用)
- 利润：利润 = 收入 - 费用 + 直接计入利润的利得 - 直接计入利润的损失

### 第二节 会计科目与账户

**账户结构（T型账）**
- 资产类：借方增加，贷方减少，期末余额在借方
- 负债类：贷方增加，借方减少，期末余额在贷方
- 所有者权益：贷方增加，借方减少，期末余额在贷方
- 收入类：贷方增加，借方减少，期末余额在贷方（结转后无余额）
- 费用类：借方增加，贷方减少，期末余额在借方（结转后无余额）

**余额公式**
期末余额 = 期初余额 + 本期增加额 - 本期减少额

### 第三节 借贷记账法 ⭐⭐⭐

**记账规则**：有借必有贷，借贷必相等

**试算平衡**
- 发生额试算：全部借方发生额合计 = 全部贷方发生额合计
- 余额试算：全部借方余额合计 = 全部贷方余额合计

**常见分录**

*采购材料付款：*
```
借：原材料
    应交税费——应交增值税（进项税额）
    贷：银行存款（或应付账款）
```

*生产领用材料：*
```
借：生产成本
    贷：原材料
```

*计提工资：*
```
借：生产成本（或管理费用、销售费用）
    贷：应付职工薪酬
```

*结转收入成本：*
```
借：主营业务成本
    贷：库存商品
借：应收账款（或银行存款）
    贷：主营业务收入
        应交税费——应交增值税（销项税额）
```

### 第四节 会计凭证与账簿

**原始凭证**：经济业务发生时取得，如发票、收据、合同
**记账凭证**：根据原始凭证填制，作为登账依据

**特别考点**
- 发现记账凭证有误：红字冲销法（金额错误）/ 划线更正法（文字错误）
- 错账更正方法：
  - 结账前：划线更正法（文字金额错误）
  - 结账后：补充登记法（少记金额）/ 红字更正法（多记或会计科目错误）

**账簿类型**
- 序时账簿（日记账）：现金日记账、银行存款日记账
- 分类账簿（分类账）：总分类账、明细分类账
- 备查账簿：对其他账簿补充说明

**对账**：账证、账账、账实核对
**结账**：月末、季末、年末办理

## 第三章 资产（最高频，最重点）⭐⭐⭐

### 第一节 货币资金

**库存现金**
- 限额：由开户银行审批
- 超出限额的现金须存入银行
- 白条不能抵库存现金

**银行存款**
- 每月至少核对一次银行对账单
- 未达账项：本已记录，对方未记，或对方已记，本方未记

### 第二节 交易性金融资产

**核算要点**
- 初始计量：以公允价值计量（交易费用计入投资收益）
- 后续计量：以公允价值计量（公允价值变动计入"公允价值变动损益"）
- 持有期间取得的股利/利息：投资收益
- 出售时：差额计入投资收益，同时转销公允价值变动损益

**分录示例**（购入股票）
```
借：交易性金融资产——成本
    投资收益（交易费用）
    贷：银行存款
```

### 第三节 应收及预付款项

**应收账款**
- 坏账损失：信用损失法（按期末余额估计）
  ```
  计提：借：信用减值损失 贷：坏账准备
  核销：借：坏账准备 贷：应收账款
  收回：借：应收账款 贷：坏账准备
        借：银行存款 贷：应收账款
  ```

**应收票据**
- 带息票据：期末计提利息 借：应收票据 贷：财务费用（红字）
- 贴现：出售票据，按实际收到金额处理

**预付账款**：发出货物或开出发票后，转为原材料/库存商品

### 第四节 存货 ⭐⭐⭐

**存货的范围**：原材料、在产品、半成品、产成品/库存商品、委托加工物资、周转材料

**初始计量**

| 取得方式 | 计量基础 |
|---------|---------|
| 外购 | 购买价格+税（不可抵扣）+运费+装卸费+保险费+相关费用 |
| 自制 | 加工过程中实际发生的各项成本 |
| 委托加工 | 实际耗用材料+加工费+税+运杂费 |
| 投资者投入 | 合同约定价值（不公允则用公允价值）|

**发出存货的计价方法**（4种）
1. 先进先出法（FIFO）
2. 加权平均法（期末一次计算）
3. 移动加权平均法（每次购入后重算）
4. 个别计价法（适用贵重/不可替代性存货）

**注意**：不得使用后进先出法（LIFO）

**期末计量**：成本与可变现净值孰低

```
可变现净值 = 预计售价 - 预计完工成本 - 预计销售费用 - 相关税费
存货跌价准备：借：资产减值损失 贷：存货跌价准备
```

### 第五节 固定资产 ⭐⭐⭐

**确认条件**（同时满足）
1. 与该固定资产有关的经济利益很可能流入企业
2. 该固定资产的成本能够可靠地计量

**初始计量**

| 取得方式 | 入账价值 |
|---------|---------|
| 外购 | 购买价格+不可抵扣进项税+运费+安装费+专业人员服务费 |
| 自行建造 | 建造完工前发生的一切必要支出 |
| 融资租入 | min(租赁开始日公允价值, 最低租赁付款额现值)+初始直接费用 |
| 投资者投入 | 合同约定价值/公允价值 |

**折旧方法**（4种）
1. 年限平均法（直线法）：`年折旧额 = (原价-预计净残值) ÷ 预计使用年限`
2. 工作量法：`单位工作量折旧额 = (原价-净残值) ÷ 预计总工作量`
3. 双倍余额递减法：`年折旧率 = 2÷使用年限×100%`；最后两年改用直线法
4. 年数总和法：`年折旧率 = 尚可使用年数/年数总和`

**不计提折旧的情况**
- 已计提折旧到期的固定资产
- 单独计价入账的土地
- 持有待售的固定资产
- 当月增加的固定资产，当月不计折旧，从下月起计

**固定资产减值**：计提后不可转回（与存货跌价准备不同）

**固定资产处置**

```
注销时：
借：累计折旧
    固定资产减值准备
    贷：固定资产（原价）

收到价款：
借：银行存款
    贷：固定资产清理

结转损益：
借：营业外支出（净损失）
借：固定资产清理（净损益）
    贷：资产处置损益（净收益）
```

### 第六节 无形资产

**范围**：专利权、商标权、著作权、土地使用权、非专利技术、特许经营权

**摊销**：合理使用年限（有限使用年限：按年摊销；无限：不摊销，但每年做减值测试）

**研发支出**
- 研究阶段：全额费用化 → 管理费用
- 开发阶段：满足5个条件可资本化 → 无形资产

### 第七节 投资性房地产

**范围**：持有目的是赚取租金或资本增值的房地产

**核算模式**（只能选一种，且不可以从公允价值模式转为成本模式）
- 成本模式：同固定资产，计提折旧、减值
- 公允价值模式：不计折旧，公允价值变动→"公允价值变动损益"

### 第八节 长期股权投资 ⭐⭐

**核算方法**

| 持股比例 | 影响程度 | 方法 |
|---------|---------|------|
| <20% | 无重大影响 | 金融资产（公允价值法）|
| 20%-50% | 重大影响 | 权益法 |
| >50% | 控制 | 成本法（合并报表用权益法调整）|

**成本法**：按实际成本入账，收到股利时
```
借：应收股利
    贷：投资收益（宣告后取得的股利）
```
或：
```
借：应收股利
    贷：长期股权投资（购买日前的股利，属于返还投资）
```

**权益法**
```
被投资方盈利时：
借：长期股权投资——损益调整
    贷：投资收益
被投资方亏损时：相反分录（但以账面价值降为零为限）
被投资方宣告分红：
借：应收股利
    贷：长期股权投资——损益调整
```

## 第四章 负债 ⭐⭐

### 第三节 应付职工薪酬 ⭐⭐⭐

**核算内容**
- 货币性薪酬：工资、奖金、津贴、补贴
- 非货币性福利
- 社会保险费（单位部分）
- 住房公积金（单位部分）
- 工会经费和职工教育经费

**基本分录**
```
计提工资：
借：生产成本（生产工人）
    制造费用（车间管理人员）
    管理费用（管理人员）
    销售费用（销售人员）
    在建工程（基建工人）
    贷：应付职工薪酬——工资

发放工资：
借：应付职工薪酬——工资
    贷：银行存款（实发）
        应交税费——应交个人所得税（代扣个税）
        其他应收款（代扣社保个人部分）
```

**非货币性福利**
```
发放自产产品：
借：应付职工薪酬——非货币性福利
    贷：主营业务收入
        应交税费——应交增值税（销项税额）
借：主营业务成本
    贷：库存商品
```

### 第四节 应交税费 ⭐⭐⭐

**增值税明细科目（一般纳税人）**
- 应交增值税下设：进项税额（借）、销项税额（贷）、已交税金、进项税额转出等
- 未交增值税：月末结转，差额为应交或待抵扣

**增值税计算**
```
月末结转：
应纳税额 = 当月销项 - 当月进项

结转应交增值税：
借：应交税费——应交增值税（转出未交增值税）
    贷：应交税费——未交增值税

缴纳：
借：应交税费——未交增值税
    贷：银行存款
```

**消费税**（价内税）
```
借：税金及附加
    贷：应交税费——应交消费税
```

**印花税**：小额可直接借记税金及附加

**个人所得税代扣代缴**
```
代扣个税：
借：应付职工薪酬
    贷：应交税费——应交个人所得税

上缴：
借：应交税费——应交个人所得税
    贷：银行存款
```

## 第五章 所有者权益

**实收资本（股本）**：注册资本，接受投资时确认

**资本公积**
- 来源：股本溢价（主要来源）、其他资本公积（含股权激励等）
- 用途：转增资本（股本），但不能用于弥补亏损

**盈余公积**
- 法定盈余公积：净利润10%提取（累计额达注册资本50%时可不提）
- 任意盈余公积：股东决定提取
- 用途：弥补亏损（先盈余公积，再实收资本）；转增资本

**未分配利润**：累计保留的利润

**股利分配顺序**
1. 弥补亏损
2. 提取法定盈余公积（10%）
3. 提取任意盈余公积
4. 支付股利

## 第六章 收入 ⭐⭐⭐

### 收入确认五步法

1. **识别与客户订立的合同**
2. **识别履约义务**（可能一合同含多项）
3. **确定交易价格**（含可变对价、重大融资成分等）
4. **将交易价格分摊至各履约义务**
5. **履行履约义务时确认收入**（时点 or 时段）

**时点确认 vs 时段确认**

时段法满足以下任一：
- 客户同步取得并消耗利益
- 创造或增强客户控制的资产
- 无替代用途且企业有权收取款项

**特殊销售处理**
- 附有销售退回条款：确认预期不会退回部分的收入，退回部分确认退货负债
- 附有质量保证条款：保证类不单独确认，服务类单独确认
- 主要责任人 vs 次要责任人（代理人）：代理人只确认净额（手续费）

### 合同成本

**合同履行成本**：能直接归属合同、且将产生未来经济利益、且能可靠计量→资产化
**合同取得成本**：增量成本（若摊销期≤1年可立即费用化）

## 第七章 费用

**营业成本**：结转的主营业务成本和其他业务成本

**税金及附加**：消费税、城市维护建设税、教育费附加、地方教育附加、房产税、土地使用税、车船税、印花税

**期间费用**（不构成产品成本）
- 管理费用：办公费、差旅费、业务招待费、研究费用等
- 销售费用：广告费、运费、展览费等
- 财务费用：利息支出净额、汇兑损益

---

## 第八章 利润

**利润构成**
```
营业利润 = 营业收入 - 营业成本 - 税金及附加 - 期间费用 - 信用减值损失
            - 资产减值损失 + 公允价值变动损益 + 投资收益 + 其他收益 + 资产处置损益

利润总额 = 营业利润 + 营业外收入 - 营业外支出

净利润 = 利润总额 - 所得税费用
```

**营业外收支**：非日常活动
- 收入：政府补助（不与资产/经营活动相关）、债务重组利得、捐赠利得
- 支出：公益性捐赠支出、非常损失

**所得税费用**：`税前利润 × 所得税税率`（简化方法）

## 第九章 财务报告

### 资产负债表

**格式**：账户式，左边资产，右边负债+所有者权益
**平衡关系**：资产总计 = 负债总计 + 所有者权益总计

**资产列报顺序**：流动性从强到弱
- 流动资产：货币资金、交易性金融资产、应收票据、应收账款、预付款项、存货等
- 非流动资产：长期股权投资、固定资产、无形资产等

### 利润表

**格式**：多步式

```
营业收入
-营业成本
-税金及附加
-期间费用（管理/销售/财务）
-信用减值损失
-资产减值损失
+公允价值变动损益
+投资收益
+其他收益
+资产处置损益
= 营业利润
+营业外收入
-营业外支出
= 利润总额
-所得税费用
= 净利润
```

### 现金流量表

**三大类活动**
1. 经营活动现金流量
2. 投资活动现金流量
3. 筹资活动现金流量

**易错点**
- 购买/出售固定资产：投资活动
- 支付利息：经营活动（企业会计准则）
- 支付股利：筹资活动

## 第十章 产品成本核算

### 费用归集

**直接费用**：直接材料、直接人工→直接计入产品成本

**间接费用（制造费用）**：按一定标准分配

分配标准：机器工时、直接人工工时、直接人工费用、直接材料消耗量等

### 产品成本计算方法

**品种法**：适用于大批量单一品种生产

**分批法**：适用于小批量、多品种、按订单生产

**分步法**：适用于大批量顺序生产
- 逐步结转：各步骤按半成品成本结转
- 平行结转：各步骤成本直接汇总到产成品

### 约当产量法（期末在产品计价）

```
约当产量 = 在产品数量 × 完工程度
完工产品成本 + 期末在产品成本 = 期初在产品成本 + 本期费用
```

## 第十一章 政府会计基础

### 政府会计体系

**双基础、双报告体系**
- 财务会计：权责发生制，编制财务报表
- 预算会计：收付实现制，编制决算报告

### 核算模式

**财务会计科目**：资产、负债、净资产、收入、费用
**预算会计科目**：预算收入、预算支出、预算结余

### 常见业务

**财政拨款**：
```
财务会计：借：财政应返还额度/零余额账户用款额度
              贷：财政补贴收入
预算会计：借：资金结存——货币资金/零余额账户用款额度
              贷：财政拨款预算收入
```

**购置固定资产**：财务会计确认资产+折旧，预算会计按实际支出确认

## 常见易错点

1. **固定资产当月增加，当月不折旧**（从下月起）
2. **固定资产减值准备不可转回**（存货跌价准备可以转回）
3. **交易性金融资产的交易费用计投资收益（借方）**（不计入成本）
4. **权益法下被投资方亏损：账面价值降至零为限**
5. **资本公积不能用于弥补亏损**（盈余公积可以）
6. **代扣个税是应付职工薪酬的减项，不是单位的费用**
7. **购买股票发生的交易费用：交易性金融资产→投资收益；长期股权投资→长期股权投资成本**

## 第一章 总论（6分左右）

### 法的本质与特征

**法的本质**：统治阶级的国家意志的体现（不是全社会成员的意志）

**法的特征**
1. 国家意志性：国家制定或认可
2. 国家强制性：国家强制力保证
3. 规范性：确定人们权利义务的行为规范
4. 明确公开性和普遍约束性

### 法的渊源（形式）⭐

| 渊源 | 制定机关 |
|------|---------|
| 宪法 | 全国人民代表大会（国家最高权力机关）|
| 法律 | 全国人大及其常委会 |
| 行政法规 | 国务院（国家最高行政机关）|
| 地方性法规 | 地方人大及其常委会 |
| 部门规章 | 国务院各部委行署 |
| 地方政府规章 | 地方人民政府 |
| 其他 | 自治条例、单行条例、特别行政区法、国际条约 |

**效力排序**：宪法 > 法律 > 行政法规 > 地方性法规 > 本级及下级地方政府规章
- 注意：判决书不属于法的渊源

### 法律主体

**自然人**：基于出生而生，有民事权利能力和行为能力
**法人**：具有民事权利能力和行为能力的组织

**民事权利能力 vs 民事行为能力**
- 自然人自出生就有权利能力
- 完全行为能力：18岁以上或16-18岁以自己劳动为主要生活来源
- 限制行为能力：8-18岁，不能完全辨认自己行为
- 无民事行为能力：不满8岁或不能辨认自己行为的成年人

### 法律责任

**民事责任**（10种形式）：赔偿损失是最主要方式
**行政责任**：行政处罚（警告、罚款、没收、暂扣或吊销许可证、行政拘留等）
**刑事责任**：主刑（管制、拘役、有期徒刑、无期徒刑、死刑）+ 附加刑

## 第二章 会计法律制度

### 会计法律体系

| 层次 | 名称 |
|------|------|
| 法律（最高）| 《会计法》 |
| 行政法规 | 《企业财务会计报告条例》《总会计师条例》 |
| 部门规章 | 企业会计准则、小企业会计准则、政府会计准则 |
| 地方性法规和规章 | 各地实施细则 |

### 会计核算基本要求

**会计凭证**
- 原始凭证：不得涂改、刮擦；错误须全部重开或更正后签章
- 记账凭证：可以涉及多个账户，但借贷方必须平衡

**会计账簿**：必须用中文记录，也可同时用外文

**会计档案保管年限**

| 档案类型 | 保管年限 |
|---------|---------|
| 会计凭证 | 30年 |
| 会计账簿 | 30年 |
| 年度财务报告 | 永久 |
| 月、季度财务报告 | 10年 |

### 会计监督

**单位内部监督**：会计机构和会计人员
**社会监督**：注册会计师审计
**政府监督**：财政部门等

### 会计机构和会计人员

**设置条件**：大中型企业需设置会计机构，聘任会计主管人员

**会计从业资格**：不再要求（2017年取消会计从业资格证书制度）

**总会计师**：协助单位负责人工作，对单位负责人负责

**会计人员法律责任**
- 行政责任：警告、罚款
- 刑事责任：伪造、变造、故意毁灭会计凭证等构成犯罪

## 第三章 支付结算法律制度 ⭐⭐⭐

### 三种票据对比（重中之重）

| 项目 | 汇票 | 本票 | 支票 |
|------|------|------|------|
| 当事人 | 出票人、付款人、收款人（可有承兑人、背书人等）| 出票人（同时是付款人）、收款人 | 出票人、付款人（银行）、收款人 |
| 付款人 | 银行或企业（银行汇票/商业汇票）| 出票人自身（银行）| 银行（开户银行）|
| 承兑 | 需要承兑（商业汇票承兑）| 不需要（见票即付）| 不需要（出票即付）|
| 付款期限 | 最长6个月 | 见票即付，最长2个月 | 出票日起10日内 |
| 背书转让 | 可以 | 不可以（不得背书转让）| 可以（记名支票可背书）|

### 银行汇票

**特点**：银行为出票人，信用度高，适合异地结算

**银行承兑汇票 vs 商业承兑汇票**
- 银行承兑：银行为付款人（信用好）
- 商业承兑：企业为付款人（信用风险较高）

**背书转让**：汇票可以背书转让多次

### 支票的种类

| 种类 | 特点 |
|------|------|
| 现金支票 | 只能提取现金 |
| 转账支票 | 只能用于转账 |
| 普通支票 | 可提现可转账 |

**支票的提示付款期限**：出票日起10日内

### 银行结算账户

**基本户**：一般经营活动结算，办理日常资金收付，只能开一个
**一般户**：特定业务资金收付，可开多个
**专用户**：特定专项资金（基建、外埠、零售）
**临时户**：临时业务

### 非现金支付工具

**网上支付**：依托银行账户
**移动支付**：通过移动通信设备

## 第四章 增值税法律制度

> 参见《初级会计运营手册》中的税法知识储备部分

### 纳税人
- 一般纳税人：年应税销售额>500万（可申请登记）
- 小规模纳税人：年应税销售额≤500万（征收率3%，目前减按1%）

### 税率
- 13%：货物（一般）
- 9%：农产品、运输、不动产等
- 6%：服务（金融、增值电信等）
- 0%：出口

### 计算公式
```
一般纳税人：应纳税额 = 销项税额 - 进项税额
小规模纳税人：应纳税额 = 不含税销售额 × 征收率
```

### 进项税额不得抵扣的情形（重点）
1. 购进的旅客运输服务、餐饮服务、居民日常服务、娱乐服务
2. 非正常损失的相关进项
3. 用于简易计税项目、免税项目、集体福利、个人消费

## 第五章 企业所得税法律制度

### 纳税人
- 居民企业：在境内注册或实际管理机构在境内 → 全球征税
- 非居民企业：在境内有机构场所的，就来自中国的所得征税

### 税率
- 一般：25%
- 小型微利企业：5%/10%（分段）
- 高新技术企业：15%

### 应纳税所得额
```
= 收入总额 - 不征税收入 - 免税收入 - 各项扣除 - 弥补亏损
```

### 扣除限额（重点）
| 项目 | 标准 |
|------|------|
| 职工福利费 | 工资总额14%以内 |
| 工会经费 | 工资总额2%以内 |
| 职工教育经费 | 工资总额8%以内 |
| 业务招待费 | 发生额60%与收入5‰，取小值 |
| 广告费和业务宣传费 | 收入15%以内（超出结转）|
| 公益性捐赠 | 年利润12%以内（超出结转3年）|

### 不征税收入
- 财政拨款
- 行政事业性收费、政府性基金

### 免税收入
- 国债利息
- 居民企业间股息红利（持股≥12个月）
- 符合条件的非营利组织收入

## 第六章 个人所得税法律制度

### 纳税人
- 居民个人：有住所或居住≥183天/年 → 全球征税
- 非居民个人：无住所且居住<183天 → 仅境内所得

### 综合所得
工资薪金 + 劳务报酬 + 稿酬 + 特许权使用费

**税率**：7级超额累进（3%-45%）

**应纳税所得额**
```
= 综合所得收入总额 - 6万元 - 专项扣除 - 专项附加扣除 - 依法确定的其他扣除
```

### 专项附加扣除（重点，2026年更新）

| 项目 | 扣除标准 |
|------|---------|
| 子女教育 | 每孩每月2000元 |
| 继续教育 | 学历400元/月；职业资格3600元/年 |
| 大病医疗 | 超1.5万部分，最高8万/年 |
| 住房贷款利息 | 首套1000元/月，最长240个月 |
| 住房租金 | 1500/1100/800元/月 |
| 赡养老人 | 最高2000元/月 |
| 婴幼儿照护 | 3岁以下每孩每月2000元（2026年新增育儿补贴）|

### 非综合所得（分类征税）

| 所得类型 | 税率 |
|---------|------|
| 经营所得 | 5%-35%（5级超额累进）|
| 利息股息红利 | 20% |
| 财产租赁所得 | 20%（月≤4000扣800元）|
| 财产转让所得 | 20% |
| 偶然所得 | 20% |

### 劳务报酬预扣率

| 预扣预缴应纳税所得额 | 税率 |
|-------------------|------|
| ≤20000 | 20% |
| 20001-50000 | 30% |
| >50000 | 40% |

### 免税所得
- 国债利息
- 按规定支付的退休金
- 保险赔款
- 省级以上政府、国家机关颁发的奖金

## 第七章 税收征管法律制度

### 税务登记

**开业登记**：开业30日内；变更30日内；注销前

**纳税申报方式**：直接申报、邮寄申报、网上申报

### 税款征收

**期限**：逾期未缴，从欠缴之日起加收滞纳金 0.05%/日

**税收保全**：书面通知银行暂停支付；扣押、查封财物（价值相当）

**强制执行**：扣缴存款；拍卖、变卖所扣押财物

**追征期**
- 一般：3年
- 特殊（偷税、抗税等）：5年
- 偷税、骗税：无限期

### 税务检查

检查权：查账、查库存、检查纳税人场所

### 法律责任

| 违法行为 | 处罚 |
|---------|------|
| 未按时申报 | 责令限期改正，处2000元以下罚款 |
| 偷税 | 追缴税款+50%-5倍罚款，情节严重构成犯罪 |
| 抗税 | 追缴税款，处罚款，构成犯罪判刑 |
| 骗取出口退税 | 追缴税款，处罚款，构成犯罪判刑 |

## 第八章 劳动合同与社会保险法律制度 ⭐⭐⭐

### 劳动合同

**订立原则**：合法、公平、平等自愿、协商一致、诚实信用

**形式**：书面（应在用工之日起1个月内订立书面劳动合同）

**期限类型**
- 固定期限
- 无固定期限
- 以完成一定工作任务为期限

**无固定期限劳动合同（应当订立的情形）**
1. 劳动者在单位连续工作满10年
2. 用人单位初次实行劳动合同制度，劳动者在单位连续工作满10年且距法定退休年龄不足10年
3. 连续订立2次固定期限劳动合同，劳动者无过失，续订时应订无固定期限

**试用期规定**

| 合同期限 | 最长试用期 |
|---------|---------|
| <3个月或以任务为期限 | 不得约定试用期 |
| 3个月-1年（含）| 1个月 |
| 1年-3年（含）| 2个月 |
| 3年以上或无固定期限 | 6个月 |

**试用期工资不得低于**：合同约定工资的80%，且不低于当地最低工资

### 劳动合同的解除

**劳动者可随时解除**：用人单位有以下情形
- 未依法为劳动者缴纳社会保险费
- 未按时足额支付劳动报酬
- 用人单位违法的

**劳动者提前30日书面通知解除**（一般解除）
**试用期提前3日通知**

**用人单位可解除（过失性辞退）**：
- 试用期不符合录用条件
- 严重违反规章制度
- 严重失职、营私舞弊，造成重大损害
- 与其他用人单位建立劳动关系，拒不改正
- 以欺诈手段订立合同
- 被追究刑事责任

**用人单位不能随意解除的情形**（不得解除）：
- 职业病或疑似职业病未确诊
- 工伤且丧失劳动能力
- 患病或非因工负伤在规定医疗期内
- 女职工孕期、产期、哺乳期
- 连续工作满15年且距退休不足5年

### 经济补偿金

**计算标准**：每满1年支付1个月工资（6个月以上不满1年按1年计；不满6个月支付半个月）

**工资上限**：补偿金月工资上限为当地月平均工资的3倍，最长12年

**需支付经济补偿的情形**：
- 合同到期不续签（单位不续）
- 非过失性辞退
- 协商解除
- 企业破产或吊销营业执照

### 社会保险

**五险**（单位和个人共同缴纳）：
- 养老保险
- 医疗保险
- 失业保险
- 工伤保险（单位全额缴纳）
- 生育保险（单位全额缴纳，2019年后与医保合并）

**住房公积金**：单位和个人各自按比例缴纳（8%-12%）

**工伤认定**（应认定为工伤）：
- 工作时间和工作场所内因工作原因受伤
- 工作时间前后在工作场所内，从事与工作有关的预备性或收尾性工作受伤
- 上下班途中受到非本人主要责任的交通事故
- 突发疾病死亡或48小时内经抢救无效死亡

## 常见易错点

1. **本票不可以背书转让**（汇票、支票可以）
2. **支票付款期限：出票日起10日内**（不是见票后）
3. **开业登记30日内**（不是15日）
4. **无固定期限合同：连续签2次后续订（非第2次）**
5. **试用期内，单位也不能随意辞退，须符合录用条件问题**
6. **工伤认定：48小时内抢救无效死亡才算工伤**（超出不算）
7. **业务招待费：取60%和5‰的较小值**（不是两者相加）
